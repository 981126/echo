# echo 常见问题排查（FAQ）

## 启动与运行
| 现象 | 原因/处理 |
|---|---|
| 打开页面显示“未登录/令牌失效” | 输入 `.env` 的 `ECHO_ACCESS_TOKEN` |
| 8000 端口被占用 | 换端口：`uvicorn app.main:app --port 8001`，前端代理同步改 |
| 5173 被占用 | Vite 会自动换 5174，照提示访问 |
| 前端 200 但接口 401 | Token 不一致，检查 .env 与登录输入 |
| 改了代码没生效 | 后端需重启（无热重载）；前端等 HMR 或强刷 ⌘⇧R |

## 素材与转写
| 现象 | 处理 |
|---|---|
| 上传后没有转写稿 | 现在上传不自动转写；进编辑页点「语音转文字」 |
| 转写一直“识别中” | 长任务会排队；若超时到通知失败，稍后重试 |
| 转写失败提示 OSS/密钥 | 检查 ECHO_ALIYUN_* 与 OSS bucket 权限 |
| 素材库顺序/时间线不对 | 时间线只看“今天及以前”、按发布时间倒序；数据缺失请先同步 |
| 卡片平台显示 “—” | 该平台未发布/未同步；点「同步数据」补齐 |

## 同步与数据
| 现象 | 处理 |
|---|---|
| 同步很慢/额度不够 | 用「同步前10条」控制频率；预算在博主页可调 |
| 某平台失败 | 单个账号「同步」按钮单独重试；失败会写在账号上 |
| 小红书/B站封面或数据缺失 | 平台接口限制；多同步几次或手动补 |
| 数据存在哪 | `.env` 的 ECHO_DATA_DIR（DB=echo.db，视频/封面在其子目录） |

## AI 与生成
| 现象 | 处理 |
|---|---|
| 生成不“像你” | 语料少：多喂真实口播；打分/改稿要勤；人设页核对风格 |
| 有 AI 腔 | 人设页加“AI 腔禁用词”；检查是否启用了最新提示词候选 |
| 双模型只一个在说话 | 检查 DeepSeek/Kimi Key 与模型名是否可调通 |
| 想换模型 | 设置页选生成模型；模型名在 .env ECHO_DEEPSEEK_MODEL/ECHO_KIMI_MODEL |
| 分数没生效 | 打分为异步回流；采用/弃用按钮与 1-5 分都会写入 |

## 备份与安全
- 每天 02:30 自动备份到 `<数据目录>/backups/`；也可手跑 `scripts/backup.sh`
- 密钥只放 `.env`；文档/提交里一律打码，绝不外发
- 清数据：停服务 → 备份 → 删 `echo.db` 与 videos/covers 下内容 → 重启（会重新建库）
