# PRODUCT — 产品说明（用户视角）

> 定位：给作者本人看的「这个系统是什么、能干什么、怎么配合使用」。
> 工程细节见 ARCHITECTURE / DESIGN，需求原文见 requirements/。

## 1. 它解决什么问题
作者在抖音 / B站 / 小红书发 1~2 分钟纯口播短视频（求职、面试、赚钱、知识赛道，仍在试错）。
- 写选题/脚本费时，且容易「不像自己、没人看」
- 发了不知道哪条为什么爆/为什么扑，复盘靠感觉
- 三个平台数据分散，手动统计麻烦

echo 的目标：让 AI 越来越懂作者的人设 ——
1. 每天按「人设 × 当日热点」自动给选题和脚本（作者人工挑选/改写后发布）
2. 已发布内容自动沉淀三平台真实数据与评论，做复盘纠错
3. 逐步帮作者找到「哪个赛道、哪种表达」更适合自己

## 2. 核心页面与用法
| 页面 | 做什么 | 常用动作 |
|---|---|---|
| 主页（时间线 + 热点选题） | 时间线看发布节奏；热点/灵感池人工挑选 | 抓取更新 → 挑灵感 → 生成草稿 |
| 素材库 | 本地素材 + 云端作品合一；上传、转写、标签、三平台合并 | 上传视频 → 编辑页「语音转文字」；卡片「同步数据」；自动合并 |
| 脚本工作台 | 草稿 / 待制作 / 废稿；Markdown 写作与改写、1-5 星打分 | 选每日选题 → 生成/改写 → 保存 |
| AI 对话 | 多会话流式问答，可查库内数据 | 问「最近哪条数据最好」等 |
| 人设档案 | 赛道/表达/红线、金句锚点；AI 建议需确认 | 补充更新，让生成更像自己 |
| 数据看板 | 指标趋势、赛道雷达、复盘 ABCD | 录入/导入/查看增长曲线 |
| 博主管理 | 主博主 + 对标；每平台账号与真实数据同步 | 配账号 → 同步前 20 条 / 全量同步 |
| AI 设置 | 模型/预算设置；生成/各功能提示词版本管理 | 配模型；看/启用新候选 |

## 3. 日常配合流程
1. **发布前**：每日看主页灵感 → 挑 1~3 条 → 工作台生成/改写 → 记住人设红线别跑偏
2. **发布后**：
   - 在素材库把视频上传/转写（可选，用于学习）
   - 在编辑页填三平台链接 → 保存 → 卡片「同步数据」（或等每日 06:00/17:00 自动同步——主博主+对标统一，R-109）
   - 评论自动入库（每平台点赞 Top50），编辑弹窗「评论数据」页可看
3. **每周/复盘**：看板看单条增长曲线与赛道雷达；跑 ABCD 复盘，把「为什么爆/扑」的建议回流到人设与生成

## 4. 数据从哪来（真实，无 mock）
- 平台互动：TikHub（抖音/B站/小红书）真实接口
- 热点：TikHub 各平台热搜
- 语音转文字：阿里云录音文件识别（FileTrans + OSS 中转，自动抽音轨）
- AI 生成/对话：DeepSeek（V4.1 Flash，`deepseek-flash`）+ Kimi 真实模型（生成默认 Kimi）
- 邮件：QQ 邮箱 SMTP（每日推送）

## 5. 边界与不做（Non-goals）
- 单用户、局域网/本机使用；不做账号体系、不自动发布、不自动剪辑/封面生成
- 不接 WorkBuddy/微信通道（未来扩展）
- 平台同步**不下载视频**；广告素材打标后不参与人设/风格学习

## 6. 常见心智模型
- 「本地素材」= 你手里有文件、可转写学习的内容；「云端作品」= 从平台同步回来、用于复盘的数据（可一键转本地）
- 「合并作品」= 同一条视频在三个平台 = 一张卡（自动/手动合并），同步/复盘按合并后的作品看
- 「同步」是拉平台最新数字与评论，**不会删除**你上传的视频、转写稿、脚本文案
