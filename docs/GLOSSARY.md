# echo 术语表（新手向）

| 术语 | 含义 |
|---|---|
| 主博主 | 你自己（当前正在经营、AI 主要学习的人设主体） |
| 对标博主 | 参考对象：只看不学，用于生成时借鉴语气/结构 |
| 本地素材 | 本地上传/转本地的素材（有视频文件，可转写学习） |
| 云端作品 | 从平台同步回来的作品（=已发布，有真实链接/时间） |
| 同一作品(work) | 同一视频发到多平台被自动合并为一组 |
| 转本地素材 | 把云端作品变成本地素材（可选带视频/文案） |
| 语音转文字(ASR) | 把视频口播转成文字稿 |
| 转写稿 | ASR 原文（只读） |
| 校对稿 | 结合你的原始文案修正后的稿（学习用它） |
| 原始文案 | 你粘贴的文案（可能与口播不一致，仅供参考） |
| 人设档案 | 标签集合：风格/赛道/红线/金句锚点 |
| 金句锚点 | 你确认过的高表现句子，生成时强注入语气 |
| 红线 | 人设边界，AI 生成不许触碰 |
| 风格画像 | 从全部文案统计出的语言习惯（句长/口头禅等） |
| AI 腔禁用词 | 生成时尽量别用的套话（首先/综上所述/赋能…） |
| 黄金样本 | 你打 4-5 分或点采用的稿，学习权重最高 |
| 讨论(双模型) | DeepSeek/Kimi 就草稿讨论 N 轮定稿，全程留痕 |
| 提示词版本 | 每个功能提示词的历史版本，可启用/回滚 |
| 同步前10条 | 每个平台拉最新 10 条作品+资料快照+评论 |
| 全量同步 | 把某博主某平台全部作品翻页拉完 |
| 预算(额度) | TikHub 每日请求上限，超限自动停止 |
| MetricsSnapshot | 本地素材按天聚合的互动指标（复盘用） |
| PlatformPostStat | 平台作品按天统计 |
| 灵感池 | 热榜+评论区提炼的“观众想知道”选题池 |
| 复盘 ABCD | A报表/B归因/C建议/D赛道方向 |
| Task/Notification | 后台任务与右上角通知 |
