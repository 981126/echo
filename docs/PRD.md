# PRD — 自媒体复盘纠错平台（echo）

> 状态：`已实现主体`（M0–M52 已完成/部分推进中，见 milestones）
> 最后更新：2026-09-06 ｜ 用户：单人（作者本人，程序员，会用 AI 工具）
> 需求原文：`requirements/`（事实源）；本文为产品范围与验收的总纲。

## 1. 背景与目标
作者在抖音 / B站 / 小红书发布 1~2 分钟纯口播短视频（求职、面试、赚钱、知识赛道，仍在试错），已有数十条历史视频。
系统目标：让 AI 越来越懂作者的人设——
- 每天自动产出与「人设 × 当日热点」匹配的选题与脚本；
- 对已发布内容做数据复盘纠错（平台数据 + 评论 + 归因 + 建议 + 赛道方向）；
- 辅助作者找到适合自己的赛道。

## 2. 非目标（明确不做）
- 不做多用户/账号体系（单用户，局域网/NAS 使用）
- 不做自动发布、不做视频自动剪辑/封面自动生成（封面作者上传，转写建议时间点为加分项）
- 不做移动端 App；Web 做响应式（手机浏览器可用）
- 暂不接入 WorkBuddy / 微信通道（未来扩展）
- 平台同步不下载视频（D-027），云端作品仅用于复盘/选题/对标；素材卡「同步数据」可按需下载视频（低清）并自动转写（R-077 ✅：抖音/小红书可用，B站受 TikHub 端点 404 限制暂不可用）

## 3. 功能范围与现状

### 3.1 项目自描述体系（M0 ✅）
AGENTS.md 入口 + docs 全套 + requirements 归档 + scripts/verify.sh 质量门禁；任何 AI 工具按同一标准流程协作。

### 3.2 内容库（素材）与转写
- 本地素材：Web 上传 + `inbox` 拖入自动入库（watcher 10s，R-033 起入库不自动转写）
- 语音转文字：编辑页手动触发 → ffmpeg 抽音轨(16k 单声道 wav) → 转写服务回填；服务商在 .env 切换（R-108 ✅）——阿里云 OSS+FileTrans 4.0 或 硅基流动 Qwen/Qwen3-ASR-1.7B（硅基流动免费）（mock|aliyun|siliconflow，改后重启生效）；ASR 原文只读、可 AI 校对稿编辑（R-032/R-033/M14/M15 ✅）；每条素材按实际转写来源与模型展示（transcripts.asr_provider / asr_model，阿里云模型为空，R-113 ✅）
- 标题/封面落盘统一「标题-视频/封面」命名（R-058 ✅）；删除素材同步清理文件
- 素材库卡片：本地+云端合一展示；封面/标签/平台三行指标占位；同排等高；点赞筛选；本地评论 tab（R-037 ✅）；编辑页封面替换+点击封面播放（R-121 ✅）；云端卡片平台名可点击跳转对应平台作品页（R-111 ✅）；广告标记合并本地素材的 is_ad（R-112 ✅）；卡片「同步数据」（R-067 ✅：绑定平台全同步 + 评论点赞 Top50）
- 素材卡「同步数据」补齐媒体（R-077/R-078 ✅）：数据同步后检查本地视频文件+转写，缺视频则从平台下载（低清；抖音/小红书走 TikHub，B站 TikHub 404 时回落 yt-dlp 直连），下载完自动触发转写（后台任务+通知）；已有则跳过
- 平台/赛道多选（platforms/main_topics JSON）；广告打标后不参与人设/风格学习

### 3.3 平台数据与博主（M13，一期 ✅ / R-030 部分待收尾）
- 博主管理：主博主(owner) + 对标(benchmark)；切换整套随动（确认弹框）；账号配置（链接解析→平台 ID、增强字段、同步开关/频率、头像）；账号行「主页 ↗」直达博主主页（R-111 ✅）
- 禁用账号的数据不在素材库展示（云端作品与绑定其作品的本地素材均隐藏，R-107 ✅）；禁用后不再自动同步，可手动同步恢复验证（R-101 ✅）
- 数据源：TikHub 真实（抖音/B站/小红书）；DataSource 适配器可整体/单平台替换（R-062 ✅）
- 同步：每日两轮（06:00/17:00，`ECHO_PLATFORM_SYNC_TIMES`）——主博主与全部对标博主统一同步（R-109 ✅）：每账号最新 15 条 + 前15条自动下载视频与转写（R-085/R-086）；博主页「全量同步」（前置）/「同步前15条」/对标账号「同步」/单账号同步、素材卡单条同步；每轮同步完成后自动触发「重新对标」刷新 Top3（R-109 ✅，替代原独立 06:00 定时 R-105）；同步带实时进度条（R-070 ✅）；同步进行中禁用对应同步/全量按钮防止重复入队（R-110 ✅）；额度护栏（默认 2000/天）+ 失败通知 + 留痕
- 评论：每平台点赞 Top50 入库展示（R-067 ✅）
- 云端作品与指标按天快照；跨平台同作品自动/手动合并（works），素材库/时间线按合并后作品去重（R-031/R-063 ✅）
- 博主对标页（R-097~R-102/R-109 ✅）：每个对标博主最新15条按互动分取 Top3（赞1+藏2+评5；广告/同款漏标过滤；转写补齐/重新对标时严格 AI 审核软广/商单/引流并排除顺延 R-103/R-106；展示时“有文案优先”，无文案/空转写被下一条顶上；文案只用 ASR 转写稿）；「转写补齐Top3」「AI可讲分析」（分析结果与进行中状态切页保留 R-114/R-116 ✅；LLM JSON 解析健壮化 R-115 ✅）「按人设洗稿存草稿」（双模型多轮讨论 R-118 ✅；来源记录+原文对照 R-117 ✅；新标题/封面字/标签/来源跳转 R-120 ✅；来源素材链接跳素材库直接打开回显、跨博主(对标)云端作品按 id 反查打开 R-122 ✅）；页顶「重新对标」一键重跑（重捞各对标最新15条 → 自动补 Top3 缺文案转写 → 刷新，R-109：10→15）；每轮每日同步（06:00/17:00）完成后自动触发「重新对标」刷新（R-109 ✅，原独立 06:00 定时 R-105 已取消）
- 选题池：三平台热点 + 主博主/对标评论（R-028 ✅ 一期）；人工挑选不自动推送
- 灵感池人设相关化（R-072 ✅）：主页「全部/只看评论/只看热榜」均衡展示；热榜按人设本地打分（红线剔除、低相关排后标注）；评论进池扩到最近 10 条作品 Top50，按点赞 + 人设相关排序

### 3.4 每日热点、选题与生成
- 热点：真实源（R-065 ✅：TikHub 热搜，抖音/B站/小红书），来源/话题缺口/换一批
- 每日流水线：热点→关键词命中匹配（可 LLM）→ 生成 ≥3 选题+脚本 → 入库幂等 →（邮件，可关）
- 每日三槽生成（R-073 ✅）：候选=评论区 1（人设筛选）+ 热榜 1（人设匹配）+ AI 建议 1（人设/热榜/评论高频/赛道缺口），缺源回退补足；TopicCandidate 记来源 slot
- 生成上下文：人设(标签/描述/红线/禁词) + 风格画像 + 检索加权样本 + 金句/最佳实践 + 对标风格卡；生成模型默认 Kimi（可 DeepSeek/双模型轮换）
- 双模型讨论（R-023 ✅）：Kimi+DeepSeek 5 轮讨论定稿留痕，失败降级
- 提示词版本化（R-021/R-022/R-057/R-064 ✅）：生成/初始化/打标/复盘等 key 独立版本、候选自动优化（每 3 条新素材/每周重建）、历史回滚
- 写作体验（R-018/R-024 ✅）：草稿三 tab（草稿/待制作/废稿）、Markdown 编辑器、插图、素材双向关联、改稿差异分析
- 反馈闭环（R-020/R-022/R-030 ✅ 部分）：1-5 星 + 四维分节评分、采用标记、金句确认、最佳实践回流

### 3.5 人设系统（M1/M5/M8/R-057 ✅）

## 6. 数据模型（概要，26 表）
见 `docs/DATABASE.md`。核心链路：
- 博主：creators → creator_accounts → creator_account_snapshots
- 云端：platform_posts → platform_post_stats / platform_post_comments；work_id→works；local_video_id→videos
- 本地：videos → transcripts / metrics_snapshots；videos → drafts
- 生产：hot_topics → topic_candidates → drafts → feedback / draft_discussions
- 系统：background_tasks / sync_jobs（含进度）/ notifications / app_kv / ai_prompts / persona_tags
