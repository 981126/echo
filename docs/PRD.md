# PRD — 自媒体复盘纠错平台（echo）

> 状态：`已实现主体`（M0–M52 已完成/部分推进中，见 milestones）
> 最后更新：2026-09-06 ｜ 用户：单人（作者本人，程序员，会用 AI 工具）
> 需求原文：`requirements/`（事实源）；本文为产品范围与验收的总纲。

## 1. 背景与目标
作者在抖音 / B站 / 小红书发布 1~2 分钟纯口播短视频（求职、面试、赚钱、知识赛道，仍在试错），已有数十条历史视频。
系统目标：让 AI 越来越懂作者的人设——
- 每天自动产出与「人设 × 当日热点」匹配的选题与脚本；
- 对已发布内容做数据复盘纠错（平台数据 + 评论 + 归因 + 建议 + 赛道方向）；
- 辅助作者找到适合自己的赛道。

## 2. 非目标（明确不做）
- 不做多用户/账号体系（单用户，局域网/NAS 使用）
- 不做自动发布、不做视频自动剪辑/封面自动生成（封面作者上传，转写建议时间点为加分项）
- 不做移动端 App；Web 做响应式（手机浏览器可用）
- 暂不接入 WorkBuddy / 微信通道（未来扩展）
- ~~平台同步不下载视频（D-027，已被 R-077/R-085 取代：每日同步会下载低清视频并自动转写 15 条）~~ 云端作品用于选题/对标；素材卡「同步数据」可按需下载视频（低清）并自动转写（R-077 ✅：抖音/小红书可用，B站受 TikHub 端点 404 限制暂不可用）

### 3.4 每日热点、选题与生成
- 热点：真实源（R-065 ✅：TikHub 热搜，抖音/B站/小红书），来源/话题缺口/换一批
- 每日流水线：热点→关键词命中匹配（可 LLM）→ 生成 ≥3 选题+脚本 → 入库幂等 →（邮件，可关）
- 每日三槽生成（R-073 ✅）：候选=评论区 1（人设筛选）+ 热榜 1（人设匹配）+ AI 建议 1（人设/热榜/评论高频/赛道缺口），缺源回退补足；TopicCandidate 记来源 slot
- 生成上下文：人设(标签/描述/红线/禁词) + 风格画像 + 检索加权样本 + 金句/最佳实践 + 对标风格卡；生成模型跟随设置 `generation_model`（默认 Kimi，可选 DeepSeek-V4.1-Flash/随机/轮流；R-135 起 `generate_draft` 也遵循该设置）
- 双模型讨论（R-023 ✅）：Kimi+DeepSeek 5 轮讨论定稿留痕，失败降级
- 提示词版本化（R-021/R-022/R-057/R-064 ✅）：生成/初始化/打标/复盘等 key 独立版本、候选**手动/按需**优化（R-131 取消自动产出，改为累计阈值提醒；金样本评测 + 历史回滚）
- 提示词优化升级（R-129 ✅）：优化语料**按 key 定制**（10 个 key 各自取真实样本，取不到则返回「样本不足，暂不优化」）、
  注入该 key 的**输出契约与上下文模板**、候选产出前做**格式契约自检**（重试 1 次）、禁止把作者传记/红线等具体事实硬写进提示词正文（运行时动态注入）、
  **提示词分层模板**（优化器只改「角色/任务」段，契约段由程序固定拼接）+ **长度预算**（超限不采纳）、
  优化模型**跟随生成模型策略**、候选 vs 当前版做**金样本回放评分**（选题 Top5 + 高/低分草稿各 3 条，自动跑，结果落库并在 UI 展示）、
  草稿记录**提示词版本**以做版本效果对比、反馈语料加厚（AI 原稿→作者改写稿 diff / 四维分节分 / 发布后真实互动）、
  候选**拒绝**与**一键回滚**
- 人设 / 提示词边界（R-130 ✅）：**单一事实源**（人设只在人设页维护，提示词正文不写死作者事实，运行时动态注入）；
  草稿记录 `persona_version` 让人设变化可控；提示词页按「人设引擎（4 个）/ 生产提示词（6 个）」分组并标注影响；
  「表达风格/禁词/金句锚点」标注为生成上下文（由人设页维护）；人设引擎候选启用后引导作者回人设页确认
- 生成「像作者」重心（R-131 ✅）：提示词**降权为「支架 + 高级设置」**——取消 generation 自动产出候选（改为累计阈值发通知 + 手动一键优化规则型），
  **重心转向数据侧**：作者改写稿（AI 原稿→作者改后）作为 few-shot 注入、风格样本检索扩容（3~8）+ 可标记「风格范本」、
  高表现内容的开场/结尾结构模板、生成后自检（红线/禁词/口癖）不达标自动重写 1 次；
  草稿记录 `persona_version` 并在版本效果对比中提示归因局限；保存草稿处引导打分
- 优化入口定位修正（R-132 ✅）：按钮改「AI 基于真实样本优化（候选）」并说明「素材/反馈更新会自动注入、无需改提示词」；
