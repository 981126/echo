# R-212 新建草稿实时保存（防「点空白处关抽屉丢内容」）

- **日期**: 2026-09-29
- **状态**: ✅ 已完成（M204）
- **关联**: `frontend_v2/src/pages/drafts/edit-drawer.tsx`（新 `autosave.ts`）、`frontend_v2/src/pages/drafts/index.tsx`；R-154（空白草稿不落库）、R-205（抽屉退场动画）、R-175/R-202（动效与非实时可见规范）

## 原文（作者原话，未改动）
> 我新建草稿打了一堆字，不小心点了其他地方导致抽屉关了，写的东西就没了，当我新建草稿做了任何变动都应该实时保存

## 根因（修复前事实）
- 「新建草稿」只把内容放进内存：`pages/drafts/index.tsx#createDraft()` → `setEditDraft(null)` + `setEditState({...EMPTY_DRAFT})`，**整篇内容直到点【保存】才会 POST**（`edit-drawer.tsx#ensureSaved()`）。
- 抽屉的遮罩点击 / 右上角 X / Esc 都走 `Drawer.onOpenChange(false)` → `onClose()` → `setEditState(null)`（`index.tsx`）；新建稿在服务端根本不存在，内容随内存一起丢弃，**不可恢复**。
- 已有草稿不受影响（`id>0`，改坏了可以关掉不保存重开）。

## 反问与确认结论（2026-09-29）
1. **范围**：只做「新建草稿」——新建稿一有改动就实时落库，并在**本次抽屉会话内持续自动保存**（否则自动建出 id 之后继续敲的字仍会丢）；**打开已有草稿维持「保存 / 取消」语义不变**（不动后端）。
2. **空稿处理**：自动保存建出的稿，若作者又把内容全部清空并关闭抽屉 → **自动删除这张空稿**（只对「本次会话自动建出」且「当前所有内容字段为空」的稿生效，不留「（无标题）」垃圾卡片）。
3. **兜底**：关抽屉（遮罩/X/Esc/关闭按钮）时**立即补一次保存**，把防抖窗口内最后几个字也落库。
4. **动效（R-175）**：底部状态位「保存中…（spinner）→ 已自动保存 HH:MM / 自动保存失败」，用 `softIn`（0.85→1 + y 3，**不从 opacity 0 起步**），收口 `opacity 1 / transform none`。
5. **按钮文案**：自动保存会话里【取消】改叫【关闭】（内容已自动保存，不存在「取消掉不存」），已有草稿仍是【取消】。

## 做法
- 新增 `frontend_v2/src/pages/drafts/autosave.ts`（不含 React/DOM 的纯逻辑，便于单测）：`draftBody / isBlankDraft / draftFingerprint` + `createAutoSaver()`。
  - **防抖** 900ms 排一次；**单飞 + 队列**：保存中再有改动入队（后写覆盖先写），当前保存完成后把最新内容继续落库（否则保存期间敲的字会被漏掉）。
  - 首次非空改动 → `POST /api/drafts`（沿用 R-154：全空不创建），成功后记住 id，后续 `PATCH`；同内容指纹不重复写。
  - `closeOut()`：关抽屉时清定时器并按当前内容补一次保存；若是「自动建出且已清空」→ 回调 `onDiscard(id)`。
- `edit-drawer.tsx` 接线：仅 `draft === null`（= 本次由【新建草稿】进入）启用；底部新增 `data-testid="draft-autosave"` 状态位；【保存】成功后标记已落库，避免重复 PATCH。
- `index.tsx`：新增 `discardAutoDraft(id)`——列表缓存里先乐观移除该行，再 `PATCH {status:'deleted'}`（逻辑删除，与卡片【删除】同口径）并刷新。
