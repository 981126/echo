# R-064-PROMPT-OPTIMIZE-CORPUS: 提示词优化基于全量素材而非最新单条

- **日期**: 2026-09-06
- **提出渠道**: 对话
- **原文摘要**: AI 提示词功能的基于最新素材优化功能（包括自动生成功能），不是单纯基于最新视频进行优化，而是当前所有的脚本文案（优先使用 ASR 转写的）、人设，并且点赞率高的文案权重更高。
- **状态**: ✅ 已完成
- **排期**: M46
- **关联**: PRD §AI 提示词（R-021/R-022/R-057）、prompt_service

## 处理结论
1. 新增 `prompt_service.learning_material(db, max_items=16)`：统一组装「优化语料」= 人设（标签/红线/金句）+ 语言习惯画像 + 全部 ASR 转写文案（当前博主、非广告），每条按「点赞率 + 互动量 + 时间衰减」加权排序，取权重最高前 N 条并附 播放/赞/藏/评 数据
2. 三个入口统一走该语料（不再只喂最新一条视频文本）：
   - 页面「AI 基于最新素材优化（候选）」：material 为空 → 自动组装全量语料
   - 每次导入新视频后的自动优化（仍每累计 3 条触发一次，防过拟合）：触发时用全量语料
   - 每周风格重建：改为同一全量语料路径
3. 优化系统提示词补充说明：素材按点赞率/互动从高到低排列，越靠前越该学
