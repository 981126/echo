## 反问与确认（2026-09-05 定稿）
1. **数据源**：改用第三方聚合平台 **TikHub**（docs.tikhub.io，非平台官方接口）；作者提供 key 配到 `.env` 的 `ECHO_TIKHUB_API_KEY`（Bearer 认证），页面提供余额/用量查询
2. **可获取数据**：三平台主页信息（粉丝/获赞/作品数）、作品列表、单作品播放/点赞/收藏/评论/转发、评论区；平台特有字段（投币/弹幕等）与原始 JSON 全部入库保留
3. **同步节奏**：每日 07:30 与 18:00 两轮，同步当前主博主三平台最新 top10 作品互动数据；素材库单条"同步数据"按钮即时同步；首次全量主博主每平台最近 50 条
4. **额度护栏**：每日请求预算默认 2000 次/天（页面可配），超限自动停止本轮并通知；失败自动重试 + 失败通知
5. **视频不下载**（省额度）：封面下载到本地缓存；云端作品进时间线并带来源标签；需要时手动"下载转素材"
6. **数据归属**：同步数据入平台侧新表（creators/creator_accounts/platform_posts/platform_post_stats/sync_jobs，见 PRD §6）；本地素材通过"发布链接/platform_post_id"与平台作品关联后，复盘/看板可打通对比
