# R-028-HOT-SOURCES: 三平台热点/评论区选题源（官方或第三方）

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 热点选题功能：核查三平台是否有可对接的热点接口，有则对接，无则推荐第三方接口；选题来源除热点新闻外，也从视频评论区挖掘大众想知道的内容。
- **状态**: 实施中
- **排期**: M13（待开工）
- **关联**: PRD §3.3/§3.10/§3.11
- **反问与确认**: 2026-09-05 定稿（见下）

## 反问与确认（2026-09-05 定稿）
1. **数据源**：统一走 TikHub（各平台热搜/话题接口 + 作品评论区接口），不再单独引入第三方热点 API
2. **评论区抓取**：主博主每日 top10 作品 × 前 20 条评论；对标每账号每日 top3 作品 × 前 20 条评论（够挖选题且控额度）
3. **选题池**：来源 = 各平台热点 + 各平台/主博主评论区 + 对标博主评论区；进选题池供作者人工挑选，不自动推送生成、不打扰
4. 原 R-025 热点池（28+ 条、平台筛选/换一批）保留，与评论区选题统一在选题池呈现

## 原文（作者原话，未改动）
