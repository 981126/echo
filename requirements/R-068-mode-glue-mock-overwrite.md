## 根因（非累加）
1. 数据库核对：该视频抖音今天存的是 10965（B站 6303 / 小红书 3165），与「按作品 ID 在 mock 假数据模式下算出的确定性数字」完全一致 → 今天同步走的是 **mock 假数据源**，不是真实 TikHub。
2. `.env` 第 53 行 `ECHO_TIKHUB_MODE=real# mock | real`：行尾注释**黏连**，pydantic 把整串当值 → `tikhub_mode='real# mock | real'` ≠ 'real' → TikHub 客户端**静默回退 mock**，把假数字写进今日快照（含播放/点赞/评论全部假）。
3. 作者看到的 5726 是真实抖音值；不是三平台累加。

2. 代码防御（config.py）：新增 `normalize_mode`——模式值自动剥离行尾注释黏连/空白；**非法值直接抛错，不再静默回退 mock**（防止假数据再次覆盖真实数据）；对 tikhub_mode / hot_source_mode / asr_mode 统一生效
