# R-034-MATERIAL-UX-FIXES: 素材库交互收尾（去掉打开本地 / 点击闪动 / 云端转写入口 / 编辑页顺序）

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 1) 「打开本地」按钮无意义，去掉；2) 点击本地素材卡片页面会闪一下（bug）；3) 云端素材也加转写按钮；4) 编辑页「原始文案」文本框放到转写框下方。
- **状态**: ✅ 已完成
- **排期**: M16（已完成）

## 处理结论（2026-09-05）
1. 云端卡片按钮「打开本地」改为「语音转文字」：点击直接进入该素材的本地编辑弹窗（内含开始转写），语义更清晰
2. 闪动修复：a) 移除本地卡片标题上的重复 @click（点击标题会冒泡到卡片根导致 openItem 触发两次）；b) `goLocal` 不再整页 `load()` 重载（避免加载中闪屏），优先用已加载数据、找不到再按 id 拉详情
3. 云端素材（已绑定本地视频的）在卡片操作区获得「语音转文字」入口；未绑定的云端素材点击后仍走「转本地素材」流程（上传文件后才可转写）
4. 编辑弹窗字段顺序调整为：语音转文字入口 → ASR 转写（只读）→ 原始文案文本框（在下方）
