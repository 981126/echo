# R-154 脚本工作台草稿：空白新建不落库 + 弹窗关闭后刷新列表

- **日期**: 2026-09-14
- **状态**: ✅ 已完成（2026-09-14，M143）
- **关联**: `frontend/src/views/DraftsView.vue`、`backend/app/schemas/draft.py`、`backend/app/api/drafts.py`

## 原文（作者原话，未改动）
> 1.我新建草稿后，关掉页面重新刷新，发现草稿tab出现了一个草稿，里面内容全是空的，如果我新建了草稿但里面没有任何内容不应该新建
> 2.在脚本工作台的新建弹窗、编辑弹窗，不论我说叉掉，还是点击保存或者取消、都需要调用查询接口，不然我需要重新切换页面才能看到新数据

## 复现与根因（2026-09-14 实测）
1. **空白稿落库**：`DraftsView.createDraft()` 点「新建草稿」时直接
   `POST /api/drafts {title:'', cover_text:'', script:''}`，记录**当场写库**；随后用户叉掉弹窗（`closeEdit` 不做任何处理），
   库里就留下一条空草稿。实测库里确有 2 条今天产生的空 `draft`（id 26/27，`title/script/tags` 全空）。
2. **关弹窗不刷新**：`closeEdit()` 只关弹窗、清状态，不调用 `load()`；因此新建后（或外部改动后）列表要等切页重挂载
   才更新。`save()` 虽然会 `load()`，但叉掉 / 取消路径不会。

## 范围
1. **新建不落库**：`createDraft()` 改为打开「本地空白稿」（`id=null`），不发请求；
   `save()` 时若 `title / cover_text / script / tags / video_id` **全为空** → 提示「草稿内容为空，未保存」并关闭，
   **不创建记录**；有任一项内容才 `POST` 创建。
2. **关闭即刷新**：`closeEdit()`（叉掉 / 取消 / 保存后统一走这里）调用列表查询 `load()`，
   刷新草稿/待制作卡片与计数，无需切页；保存新建时把 tab 切到「草稿」以便直接看到新稿。
3. **后端补齐 + 兜底**：`DraftCreate` 增加 `tags: list[str] = []` 并在 `create_draft` 做 JSON 编码
   （原来只有 `PATCH` 支持 `tags`，新建带标签需要它）；同时 `POST /api/drafts` 对「title/cover_text/script/tags/video_id
   全空」直接返回 400「草稿内容为空，未创建」，作为其它调用方的兜底（接口路径/表结构不变）。
4. **清理遗留**：把本次问题产生的空草稿（id 26/27）按应用既有语义**逻辑删除**（`status=deleted`，不物理删）。

## 不包含
- 不阻止「编辑已有草稿时清空内容后保存」（本次只针对**新建**草稿）。
- 不改草稿状态机、`/api/drafts` 路径、drafts 表结构（无迁移）。
- 不改 AI 生成 / 一键回炉 / 从热点生成等其它入口（它们有意先建占位稿）。

## 验收标准
- 点「新建草稿」不写任何内容 → 叉掉/取消/刷新后，草稿 tab **不出现**空稿。
- 新建并写了内容 → 保存后**立即**出现在草稿 tab（无需切页）。
- 编辑弹窗叉掉 / 取消 / 保存 → 列表数据被重新查询。
- `scripts/verify.sh` 全绿 + 前端点检（headless）；服务保持运行。
