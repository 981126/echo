# R-094-DOWNLOAD-TIMEOUT-ASR-FAIL-NOTIFY: 下载卡住兜底 + 转写“识别为空”原因/通知 + 合并卡单平台下载

- **日期**: 2026-09-06
- **提出渠道**: 对话
- **原文摘要**: 1.《一条视频讲清：怎么把兴趣变成饭碗》一直在“下载抖音视频”，没在下载或失败要给提示；2.转写出现“识别结果为空（SUCCESS_WITH_NO_VALID_FRAGMENT）”，应作为失败并排查原因，只要不是正常结果都要通知；3.合并卡片点同步应只下载其中一个平台的视频。
- **状态**: ✅ 已完成

## 排查与处理
1. 下载卡住：`_stream_to` 增加整体超时（8 分钟无进展即失败），读超时 300s；失败会走到“失败→通知”，不再无限“下载中”。之前《把兴趣变成饭碗》卡住大概率是抖音 CDN 拉流挂起，现在会超时并给出提示可重试。
2. “识别结果为空”：排查到两个失败样本：
   - 其中一条抖音下载产物竟是**只有音轨、没有画面的 mp3/mp4**（可能源为直播/音频类内容）；
   - 另一条前几秒静音/内容为纯背景音时也可能无有效语音片段。
   处理：转写异常现在会写 `asr_status=failed` 并给出可读原因（“未识别到有效语音：可能无声/只有背景音乐/音量过低或音轨异常”），并计入失败通知。
3. 失败必通知：逐素材队列每条失败（含超时、识别为空、无视频源、预算不足）都会 push `素材同步失败` 通知到通知栏。
4. 合并卡只下一份：
   - 素材卡点“同步”（work 级）本就按平台优先级只下载第一个可用的平台视频；
   - 逐素材队列也按 抖音→小红书→B站 排序，同一合并作品的多个平台帖只处理一次（其余标“跳过：同合并作品的视频已下载”），避免重复下载/重复评论费用。
