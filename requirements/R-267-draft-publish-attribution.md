## 一、需求背景

R-265/R-266 之后，系统能解释「哪条视频在哪一秒掉人」，也能按真实开头样本生成稿件；但它始终不知道**某一篇 AI 稿发布之后表现如何**——因为稿子和作品之间没有任何绑定。

结果是：改提示词、改门禁、加注入，全都只能靠感觉判断有没有变好。本期建立这条链路，并让效果回流到生成侧。

## 二、想要实现的目标

1. **可绑定**：每一篇要发布的稿子，能在草稿里关联到「哪条云端作品 + 哪个本地视频」，一次操作完成；
2. **可回填**：绑定后自动带上这条作品的播放、5 秒完播、2 秒跳出、完整完播、平均播放占比、互动，并与「你自己同话题同时长基线」对比；
3. **可展示**：草稿抽屉看到效果卡，脚本工作台卡片看到「已发布 · 抖音 · 播放/5 秒」小标；
4. **可回流**：这篇稿子用到的作者资产，按发布效果写入 `usage_stats.performance`，让下一次检索真正按效果排序。

## 三、页面数据来源

| 页面字段 | 数据来源 | 更新时机 | 缺失表现 |
|---|---|---|---|
| 发布状态（未绑定/已发布） | `drafts.post_id / published_at` | 绑定时写入 | 未绑定显示「标记已发布」按钮 |
| 作品选择列表 | `platform_posts`（当前主博主账号，按标题/日期搜索，最多 20 条） | 打开选择器时查询 | 无作品显示「先同步账号作品」 |
| 本地视频选择 | `videos`（当前主博主素材，按标题/文件名搜索） | 打开选择器时查询 | 可不选；选中作品若已有 `local_video_id` 自动带出 |
| 效果指标 | `platform_post_stats` + `douyin_post_metrics`（最近快照） | 绑定后立即回填；每日 05:10；抽屉手动刷新（6h 缓存） | 无私有指标 → 只显示播放/互动，并提示「该作品无创作者数据」 |
| 基线对比 | `video_review_comparison.build_comparison`（同话题同时长、同发布天数中位数） | 回填时计算 | 样本 <5 → 标「同类样本不足」，不给高低结论 |
| 资产效果 | `generation_runs.evidence_json.author_assets` → `author_assets.usage_stats` | 回填时写回 | 无生成运行/无分位 → 跳过，不写 0 |

## 四、功能需求

### 4.1 绑定（草稿抽屉）

- 新增「发布」区域，两个按钮：**标记已发布**、**解除绑定**。
- 「标记已发布」弹层：
  1. 平台：默认抖音（当前只有抖音有私有指标）；
  2. **作品**（必填）：搜索选择当前主博主账号下的作品，展示标题、发布日期、播放量；
  3. **关联视频**（可选）：搜索选择本地素材；若所选作品已有 `local_video_id`，自动带出并锁定默认值；
  4. 作品链接（可选）：默认取作品 URL，可改写。
- 保存后：写 `post_id`、`work_id`（作品的 work_id，无则空）、`video_id`、`publish_platform`、`publish_url`、`published_at`（作品发布时间，缺则当前时间），并立即回填一次。
- 「解除绑定」：清空上述字段，草稿回到未发布状态；不删除任何作品/素材。

### 4.2 效果回填

- 绑定成功后立即回填一次；之后每日 05:10 刷新全部已绑定草稿；抽屉打开时若数据超过 6 小时可手动刷新。
- 回填内容（写入 `drafts.performance`）：
  - 作品基础：`post_id / platform / title / published_at / data_time`；
  - 互动：`plays / likes / favorites / comments / shares`；
  - 留存（抖音有则写，无则 null）：`finish_5s_rate / bounce_2s_rate / finish_rate / avg_view_proportion`；
  - 基线：上述指标各自的 `baseline / percentile / state / sample_count`；
  - `refreshed_at`。
- 空值一律 `null` 并标 `missing`，**不写 0 充数**。

### 4.3 展示

- 草稿抽屉「效果」卡：
  - 有指标：播放、5 秒完播、完整完播、平均播放占比、点赞/收藏/评论，每项带「你平时 X」与样本数；
  - 抖音无私有指标：显示「该作品没有创作者数据，只有公开互动」；
  - 未绑定：显示「标记已发布后可回填效果」。
- 脚本工作台草稿卡片：已绑定的卡片显示小标「已发布·抖音 · 播放 1.2w · 5s 42%」，未绑定不显示（不占位）。
- 数据过期（>6h）：显示「数据于 X 更新」+ 刷新按钮。

### 4.4 资产效果回流

- 回填时取该草稿最近一次 `generation_runs` 的 `evidence_json.author_assets` 资产 id 列表；
- 对每个资产写 `usage_stats.performance = 5 秒完播在该作品基线里的百分位`（0~100），并记 `usage_stats.published`（次数、最近作品、更新时间）；
- 同一资产多次发布 → 取最近 5 次的**中位数**，避免单条波动；
- 无 5 秒指标（非抖音/无创作者数据）→ 不写，保留旧值。

## 五、用户故事

**故事 1（绑定）**
我写完稿子、拿另一台手机录完并发布，回到脚本工作台打开这篇草稿，点「标记已发布」，搜到我刚发的那条作品（按标题/日期都能搜到），点保存——草稿卡片立刻出现「已发布·抖音 · 播放 1.2w · 5s 42%」。

**故事 2（对比）**
打开草稿抽屉的「效果」卡，我看到这条 5 秒完播 42%，而我自己同类作品平时是 38%（样本 9 条），心里有数：这条开头略好于平时。

**故事 3（回流）**
几篇稿子发布后，系统把效果写回用到的作者资产；下一次生成时，「因为这条经历讲出来 5 秒完播高」的资产排得更靠前。

## 六、验收标准

1. **绑定**：绑定后草稿 `post_id/published_at/publish_platform` 正确；解绑后全部清空；绑定非当前账号作品 → 400。
2. **回填**：绑定作品有 5 秒完播 → `performance.metrics` 含 `finish_5s_rate` 与 `baseline/percentile`；无私有指标 → 对应字段为 null 且 `missing=true`，不出现 0。
3. **基线**：同话题同时长样本 ≥5 时给基线；<5 时 `sample_note` 写「样本不足」。
4. **每日任务**：05:10 自动刷新已绑定草稿，失败不影响其它草稿；抽屉手动刷新有 6h 缓存。
5. **资产回流**：AI 稿绑定的资产 `usage_stats.performance` 被写入分位；非 AI 稿或无分位不写。
6. **展示**：脚本工作台卡片显示已发布小标；未绑定卡片不显示该区域；0 值真实显示 0。
7. **工程**：`scripts/verify.sh` 全绿；Alembic 新列可空库升级；`docs/DATABASE.md` 同步。

## 七、不做的事

1. 不做标题自动匹配（实测 94 篇里只有 2 篇相似度 ≥0.6）；
2. 不做「录制时自动带 draft_id」（作者用另一台设备录制，链路接不上）；
3. 不做跨平台归因（只有抖音有 5 秒/完播等私有指标，其它平台只回填公开互动）；
4. 不自动把草稿改成「已发布」状态（避免误判；以 `post_id` 是否存在为准）。
