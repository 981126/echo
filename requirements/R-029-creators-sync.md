# R-029-CREATORS-SYNC: 博主管理（主/对标）+ 三平台账号配置 + TikHub 数据同步

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 经 TikHub 第三方数据平台获取抖音/小红书/B站数据；素材库单条“同步数据”按钮；每日自动同步最新作品前 10 条互动数据；博主配置页（账号 id 及扩展字段）、多博主切换；对标博主（一主多对标）；首次配置后一键同步三平台主页/作品/粉丝数据（视频不下载）。
- **状态**: 实施中
- **排期**: M13（待开工）
- **反问与确认**: 2026-09-05 定稿（见下）

## 反问与确认（2026-09-05 定稿）
1. **博主模型**：支持多个主博主（作者自己的号/马甲），每个主博主数据完全隔离（人设/素材/草稿/打分/复盘），一个主博主可配多个对标博主；**切换主博主 = AI 人设与整套数据随动，切换带确认弹框防误触**
2. **对标边界**：对标只做数据对比 + "风格参考卡"（作者手写 1-3 句风格描述 + 系统自动提取其 top 作品标题句式/题材分布）；对标内容永不进入主博主 AI 学习语料/提示词优化；对标作品可手动下载转素材但归属对标
3. **生成**：以当前主博主的人设与语料为主，可勾选"参考对标风格卡 + 参考强度"（可选关闭）
4. **存量数据**：实施时清除数据库业务数据（本地视频/封面文件保留；清库前先整库备份）；首个主博主由作者在页面手动创建，不预置
5. **账号配置页**：每博主下可配抖音/小红书/B站（架构可扩展）账号：填主页分享链接 → 系统解析 sec_user_id/user_id/uid 并回显确认；保留平台 ID 字段 + 可选增强字段（cookie/分享文本等 JSON）+ 每账号同步开关/频率/最后同步时间
6. **同步节奏**：首次全量主博主每平台 50 条 / 对标 20 条（可"加载更多"）；每日 07:30+18:00 两轮主博主 top10；对标默认手动/每周、每账号可单独开关
7. **额度护栏**：每日请求预算默认 2000 次/天（可配），超限自动停止本轮并通知
8. **云端作品**：出现在时间线并带来源标签（本地/抖音/小红书/B站/对标）
