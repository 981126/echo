## 作者确认结论

### A. 2026-09-30 已确认（保留，未改动）

1. **使用场景（决定优先级）**：作者在手机上要干四件事——**① 看数据/看概览**（主页、博主管理、博主对标）、**② 看稿背稿**（脚本工作台）、**③ 随手记灵感/写草稿**、**④ 审核与改稿**（抽屉里改正文、定稿）。
   **明确不包含**：用手机录像（R-215 的录像不手机化）、「只是应急看一眼」的低要求档。
2. **适配深度**：作者选**最深一档——「连导航一起做移动端重构」**：不只是让桌面布局收缩，而是**导航结构本身移动端化**（底部 Tab 栏 + 「更多」）。
3. **底部 Tab 栏内容（定型）**：**主页 / 素材库 / 脚本工作台 / 灵感 / AI 对话**（5 个）；
   **其余全部收进「更多」**：博主对标、博主管理、人设档案、AI 设置。
4. **最小适配宽度**：**320px 起**（iPhone SE / 老机型也不横向溢出）。
5. **提词器**：作者明确**本期先不管提词器**（`#/prompter/:draftId` 不做手机适配，也不手机化录像）。**但「脚本工作台看稿」在范围内**。
6. **验收方式**：作者选**「模拟视口 + 截图 + 探针，我自验」**——无法真机验证（只有 Playwright 模拟视口），故以 320/375/390 三档逐页探针 + 截图矩阵自验，真机由作者抽空复验。
7. **动效（R-175 / 反问清单第 9 项）**：底部 Tab 选中态用共享 layout 滑块（比照 R-204 的 `ui/tabs.tsx`）；**断点切换（桌面↔移动）不得闪白**——用 CSS 断点控制显隐而非 JS 条件渲染，避免挂载抖动与首帧空白；页面转场保持现状；**不从 `opacity:0` 起步**；尊重 `prefers-reduced-motion`。
8. **非实时返回（R-202 / 反问清单第 10 项）**：**适用**——移动端顶栏的「进行中 N」指示器必须保留且可点开（现顶栏空间紧张，需改为紧凑形态而非砍掉）。
9. **成本与性能**：零 API 成本、零 LLM 成本；纯前端；**后端零改动**。移动端首屏资源已按路由懒加载（`React.lazy`），本次不新增依赖（不引入 UI 框架，继续 Tailwind v4 + 现有 shadcn 组件）。
10. **依赖与风险**：无外部服务依赖。风险=「导航重构」会改动所有页面的外层容器，需回归全部现有 headless 点检（r206/r212/r213/r214/r217）防回归。
11. **数据**：无需新表、无需新接口、无数据迁移。
12. **优先级**：现在做。

### B. 2026-11-05 点检后需要作者拍板的 3 个口径（开发前确认）

> 这 3 项在旧文档里没写死，点检后才暴露；开发设计已给出**推荐方案**，作者确认后即按此实现。

1. **页面转场首帧透明度**：旧文档同时写了「页面转场保持现状」和「不从 `opacity:0` 起步」，而现状 `pageVariants.initial.opacity = 0` 会产生 1 帧全透明（与 R-175 冲突）。
   **推荐**：保持位移/时长/缓动不变，只把首帧改成 `opacity: 0.85`（对齐 R-175 修 Tabs 的做法），彻底消除全透明帧。
2. **移动端汉堡抽屉**：底部 Tab 上线后，是否**彻底移除**「汉堡 + 侧滑抽屉」（推荐移除，避免两套导航并存与本次发现的「空白抽屉」问题）；还是保留汉堡作为「更多」入口。
   **推荐**：彻底移除；「更多」收进底部 Tab 第 6 格。
3. **新页面纳入范围**：数据看板（R-244）与视频复盘（R-237~R-253）是 2026-09-30 之后新增/大改的页面，旧 M219 清单没有它们。
   **推荐**：一并纳入 M219（点检发现它们仍有 10px 字号、32px 控件、图表横滚、tab 裁切等问题）。

### C. 2026-11-05 作者三条硬要求（必须落进设计与验收）

> 作者原话：「m218-m220需求文档一次性全出了，注意，一定要流畅，原本有动画的地方还是需要有动画，页面符合人的使用逻辑」

1. **一定要流畅**
   - 动画只动 `transform` / `opacity`（不逐帧改宽度/高度/位置/filter）；连续滚动、切页、开关抽屉时不掉帧、不卡顿、不出现长任务跳帧。
   - 首屏与切页不闪白、不布局跳动（CLS < 0.1）；列表分页/图表加载不导致内容大幅位移。
   - 移动端自动降级「高成本特效」：`backdrop-blur`（顶栏/底栏/遮罩）在 `<md` 改半透明纯色；页面转场去掉大面积 blur；图表/列表减少同屏动画并发。**降级的是性能成本，不是动画本体**（见第 2 条）。
   - 可验收：rAF 采样（切页 / 切 Tab / 开关抽屉 / 列表换批）平均 ≥50fps、p95 帧间隔 ≤34ms、无 >100ms 长帧（无头环境若受限于 CI 需在报告注明）；CLS < 0.1；控制台 0 error。

2. **原本有动画的地方还是需要有动画（不删、不减配成瞬切）**
   - 现有 39 项动效（`motion.md` 清单）在移动端必须有对应呈现：页面转场、Tab 滑块、抽屉/弹窗/更多 Sheet 进出、列表 stagger、换批逐格交接（R-199）、参考视频切换（R-252/253）、讨论 tab（R-206）、删除重排（R-250）、thinking-dots/进度流光/进行中、通知角标、主题切换等。
   - 触屏没有 hover：**hover 才有的动画要换成触屏等价**（按下 `active`/`whileTap` 反馈、常显提示、点击后的过渡），不是删掉。
   - 只有 `prefers-reduced-motion` 用户允许收敛动画；其余情况「因为手机就砍动画」一律不合格。
   - 可验收：逐项动效在移动端有中间帧（非瞬切）——逐帧采样断言切 Tab/开合抽屉/卡片入场存在 ≥2 帧中间状态；r199/r204/r205/r206 既有动效回归全绿。

3. **页面符合人的使用逻辑**
   - 单手可达：一级入口在底部拇指区；危险/低频操作不贴边缘。
   - 返回/关闭符合直觉：Android/浏览器**返回键先关弹层**（抽屉/更多 Sheet/弹窗），不直接退页；弹层支持点遮罩/下拉/Esc 关闭。
   - 保留现场：切 Tab 再回来、开弹层再关，列表滚动位置与输入内容不丢；页面加载不自动弹键盘。
   - 键盘/触屏礼仪：AI 对话在触屏上「回车=换行、按钮发送」（桌面保持回车发送）；键盘弹起时输入框可见；不出现两层滚动互相抢手势。
   - 反馈明确：可点元素有按下反馈；耗时操作有进行中；空数据有明确指引；删除/定稿等破坏性操作二次确认。
   - 可验收：设计 5.14.7「使用逻辑点检清单」逐页通过；真机最终由作者复验。

### 1.2 为什么必须做（小白也能看懂）

- **这是早就答应的事**：D-018 决策写明「Web 要做移动端响应式，不做 App」，但 frontend_v2 从 R-164 起只做了零星断点，手机打开基本是「桌面布局被硬挤」。
- **作者真实工作流在手机上**：看数据（主页/看板/博主管理）、看稿背稿（脚本工作台）、随手记灵感、审核改稿。其中「看数据」和「看稿」都依赖**单手可达的一级入口**；左上角汉堡在手机上要两步、拇指够不到，必须换成底部 Tab。
- **现在手机上等于不可用**：点汉堡是空白抽屉（P0-1），等于没有任何页面导航；博主管理的数据行读不了、时间线要横拖 10+ 屏。
- **R-218 早已登记，本次只是补全文档并把它做成**；不做会持续影响作者日常使用与后续所有新页面（数据看板、视频复盘已经暴露同样的 10px/32px/横滚问题）。

### 1.3 与既有需求/决策的关系

- **D-018 / D-045**：导航结构定为「底部 Tab 5 项 + 更多」，断点 `md=768`，抽屉/弹窗 `<md` 全屏，触控 ≥44、字号 ≥12、safe-area、不依赖 hover。
- **R-175**：动效规范（该有的动画不能省；切换类不得从 `opacity:0` 起步、不得闪白）。
- **R-202**：非实时「进行中」移动端必须可见可点（顶栏紧凑形态，不砍功能）。
- **R-205/R-206/R-199/R-204**：抽屉退出动画、讨论 tab 动效、换批逐格交接、tab 滑块——移动端改造不得破坏这些既有动效。
- **R-244/R-237/R-252/R-253**：数据看板、视频复盘是新增/大改页面，本次一并纳入逐页适配（见 B-3 待确认）。
- **D-028/R-254 等后端规则**：与本需求无关；本次**后端零改动**。

### 1.4 风险提示

- 导航重构会改动**所有页面的外层容器**（顶栏、main、底部安全区），回归面大；必须跑既有 5 个 headless 点检 + 新建移动端点检。
- 320px 是最严苛档；5+1 个底部入口在 320 下必须用短标签（如「脚本」「对话」）并保证 44px 触控。
- 动效口径（转场首帧、reduce）需要按本文 B-1 拍板，否则 M218 会有验收分歧。

## 四、功能需求

### 4.0 总原则

1. **移动端定义**：`< md = 768px`；桌面端 `md+` 行为/样式**尽量保持不变**（除必要的公共组件全屏化/触控化按断点生效）。
2. **CSS 断点显隐优先**：导航与「移动/桌面」结构差异用 CSS（`hidden md:flex` / `md:hidden`）控制，不用 JS `useMediaQuery` 条件渲染（避免挂载空白帧/抖动）；只交互状态用 JS（如 Sheet 开合、Tab 选中）。
3. **不新增依赖**：继续 Tailwind v4 + 现有 shadcn/radix + framer-motion + lucide。
4. **后端零改动**：不改接口、不改表、不改业务逻辑。
5. **动效遵守 R-175/R-218**：切换类不闪白、不从全透明起步、尊重 reduce；保留 R-199/R-204/R-205/R-206 既有动效。
6. **所有改动可被探针验证**：每个页面改造后必须通过 `mobile-probe` 断言（见 M220 与验收）。

### 4.1 全站导航（M218）

#### 4.1.1 底部 Tab 栏（`<md` 显示）

- **入口与顺序**：主页 / 素材库 / 脚本工作台 / 灵感 / AI 对话 / 更多（6 格等分；前 5 个为页面，第 6 个打开「更多」）。
- **每格内容**：图标 + 短标签（320px 下标签用短名：主页、素材库、脚本、灵感、对话、更多；长名放 `aria-label`，如「脚本工作台」）。
- **尺寸**：整栏高度 ≥56px + `env(safe-area-inset-bottom)`；每格触控热区 ≥44×44。
- **选中态**：当前页图标+文字变主题色，共享 layout 滑块（`layoutId`）在格间平滑移动（比照 `ui/tabs.tsx` R-204）；`aria-current="page"`。
- **行为**：点击切页（路由跳转）、保留各页滚动位置（浏览器默认即可）；当前页再点不重复导航；「更多」打开底部 Sheet。
- **不压内容**：`main` 底部预留 Tab 栏高度 + 安全区（见 4.2.5），列表最后一项可完整滚动到 Tab 栏上方。
- **隐藏条件**：`md+` 隐藏；提词器页（顶层路由，不进 AppShell）不显示。
- **断点切换**：宽度拉过 768 时底部栏 CSS 消失、桌面侧栏 CSS 出现，无 JS 条件挂载，不得闪白/抖动。

#### 4.1.2 「更多」底部 Sheet

- **入口**：底部 Tab 第 6 格「更多」。
- **内容（4 项）**：博主对标、博主管理、人设档案、AI 设置。每项图标 + 名称 + 当前页高亮；2×2 网格或竖排列表（320 下优先 2×2，触控 ≥44）。
- **动效**：从底部滑入（translateY 100%→0，0.24s）+ 遮罩淡入；关闭按 R-205「受控 animate + 延迟卸载」（约 300ms 后卸载）；**不得从全透明空白起步**。
- **交互**：点条目→关闭 Sheet→跳页；点遮罩/按 Esc/下拉手柄关闭；弹层打开时锁定 body 滚动（Radix Dialog 提供）。
- **安全区**：Sheet 底部 padding 含 `env(safe-area-inset-bottom)`。

#### 4.1.3 桌面侧栏（`md+`）保持不变

- 现有 `Sidebar`（11 项、收起/展开、选中滑块）在 md+ 保持现状；仅把导航配置抽成单一数据源，供侧栏/底部 Tab/更多 Sheet 共用，避免三处菜单不同步。
- 侧栏在 `<md` 由 CSS 隐藏（现状 `hidden md:flex` 保留），底部 Tab 与其互斥。

#### 4.1.4 移动端顶栏（瘦身，不砍功能）

- 移除汉堡按钮（随底部 Tab 上线，按 B-2 推荐）。
- 保留：页面标题（超长 `truncate`）、通知铃、「进行中 N」紧凑形态、主题切换；搜索框移动端继续隐藏（现有 `hidden sm:block`）。
- 「进行中 N」紧凑形态：图标 + 数字（如旋转图标 + `2`），点击仍打开现有任务弹层；`aria-label="进行中 N"`（R-202 不回归）。
- 所有顶栏按钮触控 ≥44px；320px 下有「进行中」时标题不得换行（`truncate` + 收紧 `gap`）。

#### 4.1.5 M218-0（首个 commit，前置热修）：修复「空白抽屉」

- 在导航重构落地前，先修 P0-1：把移动抽屉里的导航改为**不受 `hidden md:flex` 影响**的导航列表（抽 `SidebarNav` 内容组件，或让外层控制显隐）。
- 验收：390/320 下打开汉堡抽屉能看到 11 个导航项且可点击跳页；关闭动画/遮罩行为保持 R-205 现状。
- 说明：该热修是过渡；M218 完成后汉堡抽屉本身会被删除（B-2 确认后）。

### 4.2 移动端系统基线（M218）

#### 4.2.1 断点

- 全站「移动 / 桌面」分界统一 **`md = 768px`**；
- 内容栅格允许在 `<md` 内继续细分（如 320→390 的单/双列），但**不得出现「640px 就按桌面布局但导航仍移动端」的矛盾**；列表类栅格把 `sm:` 多列改为 `md:` 起（或保留 2 列但补齐 320 下的可读性，见逐页）；
- 文档/设计中的移动判据只写 `max-md`/`md:` 前缀，禁止再新增 `sm:`/`lg:` 混用作「移动/桌面」判据。

#### 4.2.2 触控目标 ≥44px（移动端）

- 基础组件按断点生效（`<md` 44px，`md+` 维持现状）：`Button` 四档尺寸、`TabsTrigger`、图标按钮、`Switch` 的可点区域、`Checkbox` 行。
- 自定义可点元素（卡片操作、列表行、时间线条目、关闭按钮等）在 `<md` 保证 ≥44×44 热区（视觉可仍小，但热区要够）。
- 例外（需白名单）：正文内联链接（`a` 在段落里）、进度条拖拽等非主要操作；白名单写在 M220 探针配置里。

#### 4.2.3 字号 ≥12px（移动端）

- `<md` 下所有可见文字 ≥12px；现有 `text-[9px]/[10px]/[11px]` 在移动端统一提到 12px，桌面端维持原字号（写法：`text-xs md:text-[原px]`）。
- 图表 SVG 内的字号属性同样按断点处理（`fontSize` 10/11 → 移动 12）。

#### 4.2.4 不依赖 hover（移动端）

- 只在 hover 时出现的**功能入口**必须有触屏等价物：素材卡播放提示、封面更换、AI 对话会话管理、时间线交互。
- 纯装饰（悬停位移、缩放）可不处理，但不得作为操作提示的唯一来源。
- Tooltip 不得承担唯一语义：图标按钮必须有 `aria-label`；移动端需可见的信息不能只放 Tooltip。

#### 4.2.5 安全区

- `index.html` viewport 加 `viewport-fit=cover`；
- 底部 Tab 栏、抽屉底栏、弹窗底部操作区、AI 对话输入区、更多 Sheet 底部 padding 使用 `env(safe-area-inset-bottom)`；
- 顶部（刘海/状态栏）如页面需要（提词器除外）用 `env(safe-area-inset-top)` 兜底；
- 验收：Playwright 无法真机；按 CSS 变量存在 + 截图留证，真机由作者复验。

#### 4.2.6 键盘与动态视口

- 全站避免 `100vh` 直接算高度；AI 对话改用 `100dvh`/`visualViewport` 方案；灵感随手记输入框聚焦时保证可见（滚动补偿）；
- 键盘弹起时底部 Tab 栏保持显示，但输入区不得被键盘/ Tab 栏双重遮挡（具体方案见设计 5.12）。

#### 4.2.7 Toast/浮层

- Toast 移动端位置改为顶部居中（或底部但抬高到 Tab 栏之上），不得被底部 Tab 遮挡；
- 下拉/弹层（Select/Dropdown/Popover/MultiSelect）在 `<md` 最大宽度不超过视口（`max-w-[92vw]`），长选项 `truncate`，不得折字撑破。

### 4.3 抽屉与弹窗全屏化（M218）

- **Drawer（右侧抽屉）**：`<md` 时 100vw（`width:100%`），`md+` 保留现有 `min(680px/860px, 96vw)` 右侧抽屉；抽屉内部结构不变（header/body/footer），footer 加安全区 padding，body 底部留足滚动空间。
- **Dialog（居中弹窗）**：`<md` 近全屏（`width:100%`、`height:100dvh`、`border-radius:0`、`p-4`），`md+` 维持现有居中浮层；全部弹窗加 `max-h-[90dvh] overflow-y-auto`（或内部滚动区），保证矮屏（320×568）内容可滚、底部按钮可达。
- **底部操作区**：抽屉/弹窗底部操作区在 `<md` 固定可见（sticky/flex 不变），不得被正文遮挡；按钮 ≥44px、可换行（不缩字）。
- 涉及组件：`components/ui/drawer.tsx`、`components/ui/dialog.tsx`、`pages/videos/cloud-drawer.tsx`、`pages/drafts/edit-drawer.tsx`、`pages/videos/player-dialog.tsx`、`pages/benchmark/rewrite-diff-dialog.tsx`、`pages/creators/posts-dialog.tsx`、`components/ui/confirm-dialog.tsx`。

### 4.7 动效保留与流畅性要求（作者 2026-11-05 硬要求）

#### 4.7.1 原则

1. **不删动画**：桌面端已有的动效，移动端保留；因为触屏没有 hover，把「hover 触发」改成「按下/常显/点击后过渡」，不是取消。
2. **不瞬切**：不允许用 `display: none/block`、条件卸载替代有过渡的交互（抽屉、弹窗、Sheet、Tab、列表进出场都要有可感知的过渡）。
3. **允许的唯一收敛**：`prefers-reduced-motion: reduce` 用户；其余一律保留。
4. **降本不降效果**：通过只动 GPU 属性、限制同屏动画数量、去掉大面积 blur/backdrop-filter 来保流畅，而不是删动画。
5. **桌面不回归**：`md+` 的动效参数、时长、曲线保持现状。

#### 4.7.3 流畅性预算（移动端）

| 指标 | 要求 |
|---|---|
| 帧率 | 关键动效（切页/Tab/抽屉/列表换批）平均 ≥50fps，p95 帧间隔 ≤34ms |
| 长帧 | 无 >100ms 长帧（无头 CI 环境如受限制需在探针报告注明环境） |
| CLS | 首屏与切页 < 0.1 |
| 只动 GPU 属性 | 动画的逐帧属性只允许 `transform`/`opacity`；高度展开类动画仅限小区域（如记反馈区） |
| 同屏并发 | 列表 stagger/图表动画同时进行的元素数设上限（列表 ≤12、图表 ≤6），其余直接落定 |
| 重特效降级 | `<md` 顶栏/底栏/遮罩去掉 `backdrop-blur`（改 95% 纯色）；页面转场去掉 blur；低端机可选 `will-change` 最小化 |
| 资源 | 保持路由懒加载；大图继续走缩略图/懒加载；不因适配新增第三方库 |

#### 4.7.4 允许 vs 禁止的降级

| 允许 | 禁止 |
|---|---|
| 移动端去掉 blur/backdrop-filter 省 GPU | 把抽屉/弹窗改成瞬间出现 |
| 减少同屏动画数量/错峰 | 整页取消列表入场动画 |
| 首帧透明度提高（0→0.85）避免白闪 | 用 `display` 切换替代退出动画 |
| reduce 用户收敛动画 | 普通用户「手机性能差」为由删动画 |

### 4.8 使用逻辑要求（作者 2026-11-05 硬要求）

#### 4.8.1 导航与返回

- 一级入口在底部 Tab（拇指区）；「更多」收纳低频入口；桌面侧栏保持。
- **浏览器/Android 返回键先关闭当前弹层**（更多 Sheet、抽屉、弹窗），没有弹层时才返回上一页；不允许返回键直接退页而弹层还开着。
- 弹层关闭方式：关闭按钮（≥44）、点遮罩、Esc、更多 Sheet 支持下拉手柄。
- 切 Tab 使用正常路由跳转；点当前 Tab 不重复入栈、不闪动。

#### 4.8.2 滚动与现场保持

- 切 Tab 再回来：保留该页滚动位置（首次进入在顶部）；从抽屉/弹窗关闭后列表位置不跳。
- 弹层打开时锁定背景页面滚动（不能出现「背页跟着滑」）。
- 横向滚动只在明确允许的区域（Tab 行、图表容器）且要有可滑提示；页面本身不允许横向滚动。
- 退出页面/弹层不丢未提交输入（草稿自动保存/灵感输入保持现状）。

#### 4.8.3 键盘与输入

- AI 对话：触屏上回车 = 换行，发送用按钮；桌面保持回车发送。
- 输入框聚焦时自动滚动到可见区域（键盘不遮挡）；页面加载**不自动聚焦**、不自动弹键盘。
- 灵感随手记 / 草稿编辑抽屉：键盘弹起时「保存/记下」仍在可达位置或可滚动到。

#### 4.8.4 触屏手势与误触

- 可点元素按下有即时反馈（`active`/`whileTap`），响应 <100ms。
- 触控目标 ≥44×44；相邻危险按钮（删除/定稿）与普通按钮拉开间距，破坏性操作二次确认。
- 抽屉/Sheet 支持从顶部向下拖拽关闭（更多 Sheet）；拖拽不能误触发页内滚动。
- 列表滚动时点击不误触（滚动判定阈值由浏览器默认处理，不自定义手势拦截纵向滚动）。

#### 4.8.5 弹层与安全区

- 全屏抽屉/弹窗顶部/底部内容不贴屏幕边缘（≥16px），底部按钮区避开 iPhone home indicator。
- Toast 在移动端不被底部 Tab 遮挡（顶部居中或抬高）。
- 弹层内二级弹层（确认框）关闭后回到原弹层，不整页跳走。

#### 4.8.6 加载 / 空 / 失败反馈

- 列表加载有骨架/加载提示；空数据有「去做什么」的指引（保持现有文案口径）。
- 耗时操作（同步/生成/转写/分析）有进行中动效，切页/刷新可恢复（R-202）。
- 失败有明确 toast/提示与重试入口，不允许静默失败。
