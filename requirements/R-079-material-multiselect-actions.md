# R-079-MATERIAL-MULTISELECT-ACTIONS: 素材库悬浮按钮改「多选」→ 批量删除/合并/同步

- **日期**: 2026-09-06
- **提出渠道**: 对话
- **原文摘要**: 素材库中悬浮的【合并】按钮改成「多选」；点开后可以多选做 删除、合并、同步。
- **状态**: 澄清中（待作者确认范围/同步语义后实施）
- **排期**: M61
- **关联**: PRD §3.2（素材库）、VideosView、works merge/split、删除(videos/works)、R-067/R-070/R-077 同步链路

## 现状（代码事实）
- 悬浮 `.merge-float`：现为「合并」按钮 → 进入合并模式，仅云端卡可勾选，操作仅「合并所选（≥2）」+「取消」（VideosView.vue）。
- 单卡已有：删除本地(delLocal)/删除云端(delCloud)、同步数据(syncData/syncCloudPost，R-067 起含媒体补齐 R-077)、拆分(splitWork)。
- 后端已有：`/api/works/merge`、`/api/works/{id}?kind=work|post` 删除、`/api/works/{id}/sync`、`/api/platform/posts/{id}/sync`、`/api/platform/videos/{id}/sync`。

## 需求方案草案
1. 悬浮按钮文案改「多选」：进入多选模式后任意卡可勾选（范围见待确认 Q1），底部操作条提供：删除所选 / 合并所选（仅云端、≥2）/ 同步所选 / 取消。
2. 批量删除：本地卡连同文件清理、云端卡删合并作品或单条（沿用现有确认与后端），一次提交一组。
3. 批量合并：复用 `/api/works/merge`（仅云端卡、去重、≥2）。
4. 批量同步：逐张执行「同步数据」（语义见 Q2），统一 loading 与结果汇总。
5. 结束/取消：清空选择退出多选，刷新列表。

## 待确认
Q1 多选范围：A) 云端+本地素材卡都能勾（合并仅云端≥2，删除/同步两者可用）；B) 仅云端卡（同现状合并模式）。
Q2 批量「同步」做什么：A) 仅刷新数据+评论，不触发视频下载/转写（避免一次多张触发大量下载+ASR 成本）；B) 等同逐张点「同步数据」（含 R-077 媒体补齐）。
Q3 批量删除确认：沿用单卡确认弹窗（本地连文件删除）？（推荐沿用）
