# R-184 反馈闭环：发布回填 + 一键反馈 + 风格范本引导

- **日期**: 2026-09-28
- **状态**: 🔲 已确认方向，待实施
- **关联**: `drafts`（加发布字段）、`feedback`、`api/drafts.py`、前端脚本工作台；R-020/R-022/R-131/R-156

## 原文（作者原话，未改动）
> （讨论「越做越久越没灵感」的闭环时确认）先建反馈闭环。

## 背景
学习闭环的数据极少：`feedback` 仅 23 条（4 条评分、3 条点赞）、`draft_versions` 7 条、未设风格范本。
管线（改稿差异分析 R-156/157）已存在，但「发没发、表现如何」回不来，飞轮转不动。
**作者改稿是最值钱的训练数据。**

## 方案
1. 草稿加发布字段：`publish_url` / `published_at` / `publish_platform`；「完成」时引导填发布链接。
2. 发布后 24h 自动回填指标（复用现有平台指标快照）挂到稿子上，形成「稿子 → 表现」归因。
3. 卡片加**一键「好 / 差」**（降低反馈成本），并入 `feedback` 回流提示词优化与结构模板。
4. 人设页/AI 设置引导作者挑 5–10 条「最满意的声音」为风格范本（入口已有，零开发，属必做动作）。

## 验收
- 草稿可记录发布链接/时间/平台；发布后能自动回填表现；
- 一键反馈可用并回流；`scripts/verify.sh` 全绿。
