# R-041-LIBRARY-FIRST-RENDER: 素材库首屏先显示一条再补齐问题

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 为什么打开素材库，会先展示一条数据，然后再把其他的数据加载出来。
- **状态**: ✅ 已完成
- **排期**: M23（已完成）
- **关联**: PRD §3.5、R-040

## 原因与处理（2026-09-05）
1. **原因**：首屏挂载是串行的——先 `load()`（只拉本地素材）并立刻渲染，再 `loadWorks()`（云端作品）再渲染一次；本地只有 1 条时会先出现 1 张卡片，云端几百条随后才补上
2. **处理**：新增 `initLoad()`：本地素材与云端作品**并行**拉取，全部到齐后再统一 `buildCards()` 渲染一次
3. 刷新/删除后的局部刷新仍复用原 load()/loadWorks()，不影响操作流畅度
