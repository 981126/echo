# R-112 三处线上修复：卡片广告标记 / 通知复制 / ASR 来源展示

- **日期**: 2026-09-07
- **状态**: ✅ 已完成
- **排期**: M95（已完成，线上 bug 修复）
- **原文**:
  1. 《线下课详细介绍：一套判断力操作系统》明明素材里面已经标志成广告，为什么素材卡片上不展示广告
  2. 右上角通知，我展开，有时候想复制，它又缩起来了
  3. 《聊过很多老板，都说挣钱的核心不在于干什么》明明用的是硅基流动的 qwen 模型转译的文字，为什么卡片编辑页还展示成阿里云了

## 根因与修复
1. **卡片广告标记缺失**：本地素材转本地后，卡片由云端合并卡展示，`is_ad` 只取 posts（未同步本地 video 的广告标记）。前端 `VideosView.buildCards` 云端卡合并时叠加绑定本地素材的 `is_ad/ad_price`。
2. **通知展开后复制会收起**：面板「点击外部关闭」挂在 `click` 上，选文字拖出面板边缘时 mouseup 落在面板外会误关。改为 `pointerdown`（按下点是否在面板内）判定；并给每条通知加「复制」按钮（复制标题+内容，不关闭面板）。
3. **编辑页 ASR 来源写死为「阿里云」**：`TranscribeSection.vue` 文案硬编码。新增 `GET /api/settings/asr` 返回当前 asr_mode/model，前端据此显示「硅基流动 ASR · Qwen/Qwen3-ASR-1.7B」「阿里云 ASR」或「模拟」。

## 验收
- 已标记广告的本地素材，其云端合并卡上出现「广告」标签。
- 通知展开后可用「复制」按钮复制，且面板内选文字不会误关闭。
- 编辑页转写区按当前 `.env` 的 ASR 模式显示正确来源。
- `scripts/verify.sh` 全绿。
