## 方案与实施结论（M63）
1. 后端进度持久化：`background_tasks` 增加 `note` 列（阶段说明，幂等迁移 R-081）；`/api/tasks` 支持按 `status`/`kind` 过滤；TaskOut 返回 note。
2. 媒体补齐任务（platform_media）通过任务运行器注入的 update 回调实时回写进度百分比与阶段文字：检查视频文件/准备下载 → 正在下载视频（抖音/小红书/B站）→（B站 ffmpeg 合并）→ 语音转写中（可能几分钟）→ 完成。
3. 前端覆盖层两段式：请求阶段（数据/评论同步中…，本地过渡）；进入后台媒体任务后进度与文字全部来自后端轮询；切页回来或跨页触发的同步，会在页面挂载时/每 6s 扫描 running 的 platform_media 任务，按 payload 匹配素材卡自动恢复覆盖层与文字。
4. 覆盖层中央显示阶段文字 + 百分比（如「正在下载视频（抖音）… 42%」「语音转写中（可能需要几分钟）… 88%」）。
5. 自测：verify.sh 全绿；接口/表结构文档（API.md/DATABASE.md）同步更新。
