# R-239：账号级创作者 Cookie 与数据源策略（视频复盘配置下移博主管理，合并 R-238）

- **日期**：2026-10-30
- **提出渠道**：对话
- **状态**：✅ 已完成（2026-10-30，verify 全绿 + 真实接口冒烟）
- **开发设计**：`development-design/R-239-account-cookie-data-source.md`
- **合并说明**：R-238（素材库本人抖音改创作者中心、素材卡显示播放）经作者确认**并入本需求**，不再单独实施；R-238 的素材库播放展示、回填与防覆盖作为本需求的一部分。
- **依赖**：R-237（创作者中心真实取数能力，当前在 `feat/r237` 工作区未提交）

## 1. 需求背景

R-237 上线后，抖音创作者 Cookie 只能在「视频复盘 → 抖音数据设置」里配置。这个位置有三个问题：

1. **入口不对**：Cookie 本质是“某个平台账号的凭据”，应该跟账号一起管理；作者在博主管理里维护账号时找不到配置入口。
2. **只看一个账号**：整站默认只给当前主博主的抖音账号配 Cookie；但数据收集或对标账号里如果有已授权账号，也应该能按账号配置。
3. **失效处理粗**：Cookie 失效后，系统仍会继续用公开接口重复请求，既拿不到播放量、又浪费 TikHub 额度；作者只能通过视频复盘页面的报错感知，不知道是哪个账号失效，也没有通知。

另外 R-238 已确认的素材库问题也需要一起解决：素材库自己抖音作品播放量恒为 0（公开接口不返回播放），页面只显示点赞，且公开同步的 0 会把创作者接口写入的真实播放覆盖掉。

作者明确的新规则（2026-10-30 确认）：

- 每个账号编辑页面，在 Cookie 前面加一个开关：关闭则不走创作者中心；开启且配置了 Cookie 才走创作者中心。
- 收集该账号数据时，如果开关开启且已配 Cookie，检查到 Cookie 失效：**停止收集该账号数据**，发通知并把账号标记为“Cookie 失效”；该账号**所有第三方接口都不调用**，直到修改 Cookie。
- 没有配置 Cookie 的账号，直接使用公开接口。

## 2. 想要实现的目标

### 2.1 核心目标

1. **Cookie 配置下移到博主管理**：视频复盘去掉 Cookie 配置入口；每个账号的「编辑账号」弹窗里增加「抖音创作者数据」开关 + Cookie 配置 + 状态显示。
2. **账号级数据源策略**：每次收集某账号数据前先判断——开关关闭或没配 Cookie → 公开接口；开关开启且 Cookie 可用 → 创作者中心接口（抖音）；开关开启但 Cookie 被判定失效 → 该账号进入“Cookie 失效”状态，停止一切第三方调用并发通知，直到更新 Cookie。
3. **失效可见、可恢复**：博主管理账号行显示 Cookie 状态（未配置/已关闭/可用/已失效）；失效通知直达作者；重新保存有效 Cookie 后自动恢复。
4. **视频复盘不再管 Cookie**：页面只读展示账号创作者数据状态；失效时提示去博主管理更新；分析任务按账号策略决定用创作者或公开数据。
5. **合并 R-238**：素材库卡片显示真实播放量；创作者真实播放不被公开接口 0 覆盖；首次自动回填历史、每日自动保鲜；素材卡数据来源可信标记。
6. **先只做抖音**：B 站/小红书的数据源、B 站现有 yt-dlp Cookie 字段、评论正文、视频下载、对标/低粉搜索等保持现状。

### 2.2 完成后的可见结果

- 视频复盘页不再出现「抖音数据设置」按钮和弹窗；顶部只显示“创作者数据：可用 / 未配置（去 博主管理 配置）/ 已失效（数据收集已停止）”。
- 博主管理 → 某账号 →「编辑账号」：抖音账号能看到开关、Cookie 输入框、当前状态、最近成功时间；保存时真实校验并给出结果。
- 账号行出现状态徽标；Cookie 失效时通知中心出现一条通知，本账号不再产生任何第三方请求。
- 素材库自己抖音作品卡片显示「▶ 真实播放 👍 点赞」；历史作品自动补齐；每天自动更新，不再被公开同步冲成 0。
- 没有 Cookie 的账号正常按公开接口收集数据，和现在一致。

### 2.3 明确不做的范围

- 不改 B 站/小红书的数据源，不动 B 站现有 yt-dlp Cookie（`extra_config.cookie`）。
- 不新增“平台账号登录页/扫码授权”，仍是手动粘贴 Cookie。
- 不把评论正文、视频下载改成创作者接口（创作者中心没有对应接口）；账号正常时这两类继续走公开接口，账号失效时一并停止。
- 不补历史每日播放快照（平台只给当前累计值），只补当天统计。
- 不做 Cookie 自动续期（抖音不提供）。
- 不改变素材库卡片布局、筛选、分页方式。

## 3. 页面数据来源

| 数据 | 从哪里来 | 何时更新 | 需要什么权限 | 拿不到时页面怎么显示 |
|---|---|---|---|---|
| 账号 Cookie 开关/状态 | 本地库（账号凭据表） | 保存账号、每次数据收集判定后 | 仅作者本机 | 新建账号显示“未配置”；已关闭显示“已关闭” |
| 抖音作品列表/播放/点赞/评论/收藏/转发 | 开启且有 Cookie：创作者中心；否则公开接口 | 手动同步、每日两轮同步、首次回填 | 对应账号的抖音创作者 Cookie | 失效：账号状态“已失效”，停止同步；无 Cookie：公开数据（播放显示暂无） |
| 2 秒跳出率/5 秒完播/完播率/平均播放/主页访问/吸粉量 | 创作者中心 | 同上 | 同上 | 入库为空；素材库一期不展示 |
| 评论正文 | 公开评论接口（账号正常时） | 点加载评论/同步 | TikHub API Key | 账号失效时暂停，显示旧数据 |
| 视频文件地址 | 公开视频详情接口（账号正常时） | 媒体补齐 | TikHub API Key | 账号失效时暂停 |
| 素材库播放量/点赞 | 平台统计（来源按账号策略） | 同步数据/每日保鲜/回填 | 同上 | 未知显示“暂无”；真实 0 显示 0 |
| Cookie 失效通知 | 系统通知中心 | 首次判定失效时 | — | 通知中心可见；可跳转博主管理 |

## 4. 功能需求

### 4.1 视频复盘去掉 Cookie 配置

- **移除**：视频复盘页的「抖音数据设置」按钮、Cookie 弹窗、Cookie 输入与保存逻辑、页面内所有 Cookie 配置入口。
- **保留只读展示**：在视频复盘顶部/账号行附近显示当前账号创作者数据状态：
  - 可用：「创作者数据可用（博主管理 → 编辑账号 配置）」。
  - 未配置/已关闭：「创作者数据未启用，当前使用公开数据」。
  - 已失效：「该账号创作者 Cookie 已失效，数据收集已停止，请到 博主管理 → 编辑账号 更新 Cookie」。
- **分析行为**：点「更新数据并分析」时按账号策略执行：
  - 可用：创作者中心刷新作品指标 + 正常分析。
  - 未配置/已关闭：公开接口刷新（播放为 0/暂无）+ 正常分析。
  - 已失效：不发起任何第三方请求，任务直接失败并提示去更新 Cookie。
- **不新增**视频复盘里的跳转按钮（仅文字引导；如需跳转见验收确认）。

### 4.2 博主管理账号编辑（Cookie 配置）

- **入口**：博主管理 → 账号行「编辑」→ 现有「编辑账号」弹窗（扩展，不新增独立页面）。
- **仅抖音账号显示**「抖音创作者数据」区块（B 站/小红书不显示；B 站原有 yt-dlp Cookie 字段保持不动）：
  - **开关**：`启用创作者中心数据`（默认开）。关闭后即使有 Cookie 也只走公开接口。
  - **Cookie 输入框**：粘贴完整创作者中心 Cookie（含 sessionid/sid_tt）；已保存的 Cookie 不回显，输入框留空表示“不修改”。
  - **状态**：未配置 / 已关闭 / 可用（最近成功时间）/ 已失效（错误原因摘要）。
  - **保存并验证**：点击后用最小真实请求校验；成功则状态“可用”；失败提示原因并把状态置“已失效”。
  - **仅切换开关**：不重新输入 Cookie 也可以保存开关；开关打开但无 Cookie 时提示“请粘贴 Cookie 后再开启”。
- **账号行/列表**：显示状态徽标（可用/未配置/已关闭/已失效）；失效账号行有明确文字提示。
- **数据安全**：Cookie 加密入库、不回显、不进日志/任务/AI 输入；接口返回仅状态，不返回明文。
- **失败表现**：Cookie 格式非法/校验失败 → 提示可读原因（如“未登录或已过期”），状态标为失效；网络/额度失败 → 提示“暂时无法验证，请稍后重试”，状态不误改为失效。

### 4.3 账号级数据源选择规则

每次收集某账号数据前（列表、指标、素材库同步、视频复盘刷新等），执行统一判断：

| 账号状态 | 数据源 | 行为 |
|---|---|---|
| 抖音账号 + 开关关闭 | 公开接口 | 正常公开收数（播放 0/暂无） |
| 抖音账号 + 开关开启 + 未配置 Cookie | 公开接口 | 正常公开收数 |
| 抖音账号 + 开关开启 + Cookie 可用 | 创作者中心（指标/列表）；评论/媒体仍公开 | 创作者取数；账号有效 |
| 抖音账号 + 开关开启 + Cookie 失效 | **停止** | 本账号所有第三方接口都不调用；发通知；标记失效 |
| B 站/小红书（任意） | 现有公开接口 | 不变（B 站 yt-dlp Cookie 不动） |

补充规则：

- 失效后再收集：不发起请求、不再重复建通知，只把账号状态和原因显示出来。
- 更新 Cookie 并校验成功后：状态恢复“可用”，下次收集自动恢复创作者中心。
- 作者手动把开关关掉：视为明确选择公开数据，解除“失效停采”状态，恢复公开收数（但 Cookie 仍保留，重新开开关需再次校验）。
- 同一账号的失效通知只发一次（状态从可用/未验证变为失效时）；重复失败不刷屏。
- 账号失效时，评论/媒体/素材库同步等依赖该账号的链路全部暂停，并在返回信息里说明“账号 Cookie 已失效”。

### 4.4 素材库数据与播放展示（合并 R-238）

- **卡片显示**：自己抖音作品（以及所有有可信播放来源的作品）显示「▶ 播放量」「👍 点赞」。
  - 真实 0 显示 0；未知（公开接口的 0）不显示数字。
  - 来源可信标记由后端返回，前端不猜。
- **同步数据**：按 4.3 规则取数；失效账号不发起请求，提示去博主管理更新。
- **防覆盖**：同一天多来源写入时，创作者真实播放不能被公开接口的 0 覆盖；记录来源。
- **首次回填**：首次上线自动回填该账号全部抖音作品当天统计；按时间窗分页，请求有上限，失败可续跑。
- **每日保鲜**：每日两轮同步后自动刷新最近 90 天作品；失效账号跳过并保持停止状态。
- **主页访问/吸粉/完播等**：入库供视频复盘使用（素材库一期不展示）。

### 4.5 空数据与失败表现汇总

| 情况 | 页面/接口表现 |
|---|---|
| 账号未配置 Cookie | 状态“未配置”；公开数据；素材库播放未知不显示 0 |
| 开关关闭 | 状态“已关闭”；公开数据 |
| Cookie 校验失败（保存时） | 提示原因；状态“已失效”；不保存为可用 |
| 收数时发现失效 | 停止该账号所有第三方调用；通知中心一条通知；账号行标“已失效” |
| Cookie 失效账号再同步 | 不发请求；返回“账号 Cookie 已失效，已停止收集”；不重复通知 |
| 更新有效 Cookie | 状态恢复“可用”；通知不再出现；恢复收数 |
| 网络/预算临时失败 | 不标失效；提示稍后重试；保留旧值 |
| 素材库无统计行 | 播放不显示；不显示 0 |
| 后台回填进行中 | 任务中心/通知显示进度；切页/刷新可恢复 |

## 5. 用户故事

1. **作为**作者，**我希望**在博主管理编辑某个账号时就能配置它的抖音创作者 Cookie，**以便**不用为了配 Cookie 专门跑到视频复盘。  
   **可见结果**：编辑账号弹窗有开关、Cookie 输入框、状态和「保存并验证」。
2. **作为**作者，**我希望**关掉某个账号的创作者开关后它只用公开数据，**以便**临时不想用创作者接口时可控。  
   **可见结果**：开关关闭后同步不调用创作者接口，账号状态显示“已关闭”。
3. **作为**作者，**我希望** Cookie 失效时系统自己停下这个账号的收集并通知我，**以便**不再白扣额度、也知道该处理哪个账号。  
   **可见结果**：通知中心出现一条“账号 xxx Cookie 已失效”；账号行标红/标“已失效”；之后该账号不再有任何第三方请求。
4. **作为**作者，**我希望**更新 Cookie 后账号自动恢复收集，**以便**不用手动重开各种同步。  
   **可见结果**：保存有效 Cookie 后状态变“可用”，下一次同步恢复创作者数据。
5. **作为**作者，**我希望**视频复盘不再出现 Cookie 配置，只告诉我状态和去哪里改，**以便**页面干净且不会配错地方。  
   **可见结果**：视频复盘只有一行状态提示，没有配置按钮/弹窗。
6. **作为**作者，**我希望**素材库自己的抖音视频能看到真实播放量，**以便**判断哪条内容有效（原 R-238）。  
   **可见结果**：素材卡显示「▶ 3,587 👍 46」；历史自动补齐。

## 6. 验收标准

- [ ] 视频复盘页面不再有 Cookie 配置按钮/弹窗/输入框；状态提示只读，失效时引导去博主管理。
- [ ] 博主管理「编辑账号」弹窗：抖音账号有开关 + Cookie 配置 + 状态显示；未回显已保存 Cookie；开关与 Cookie 均可保存。
- [ ] 开关关闭 → 同步不走创作者接口（可用日志/响应 `data_source=public` 证明）。
- [ ] 开关开启 + Cookie 可用 → 抖音账号列表/指标走创作者中心（`data_source=creator`，播放真实）。
- [ ] 开关开启 + Cookie 失效 → 该账号所有第三方接口停止（无新请求/无新统计写入），通知中心仅一条通知，账号标记“已失效”。
- [ ] 失效账号在修复 Cookie 前，每日同步/素材库同步/视频复盘均不再请求第三方，并明确提示原因。
- [ ] 保存有效 Cookie 后账号恢复“可用”，同步恢复创作者数据。
- [ ] 无 Cookie/开关关闭的账号仍走公开接口，原有 B 站/小红书/评论/媒体行为不变。
- [ ] 素材库自己抖音卡片显示真实播放；公开同步不覆盖真实播放；首次回填后播放>0 覆盖达标（原 R-238 验收）。
- [ ] Cookie 加密存储、不回显、不进日志/任务/AI；`scripts/verify.sh` 全绿；真实接口冒烟 + 页面点检。
- [ ] 新增/修改表字段有 Alembic revision 且 `docs/DATABASE.md` 同步；接口变更同步 `docs/API.md`。
