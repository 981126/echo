## 核查结论（2026-09-05）
1. 云端发布时间本身是有的：1169 条 platform_posts 全部有 publish_time（2024-03 ~ 2026-09 真实历史时间），非缺失问题
2. **顺序乱根因**：时间线事件里本地视频 id 与云端作品 id 都是数字、会撞号 → Vue v-for key 重复 → 渲染顺序错乱；已给每个事件加唯一 key（v{id} / c{id}）
3. **滑到后面没内容根因**：首页时间线此前只拉云端**最新 300 条**（老作品根本没进时间线），不是“没时间”；已改为拉取全量（limit 2000，当前 1169 条全含）
