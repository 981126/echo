# R-091-CREATOR-SYNC-CARD-ANIMATION: 博主页同步开始即让素材库已有素材进入动画

- **日期**: 2026-09-06
- **提出渠道**: 对话
- **原文摘要**: 在博主页面点击同步、同步前15条的时候，如果发现素材库已有的数据，那么素材库的那些同步的素材立刻进入动画状态。
- **状态**: ✅ 已完成
- **排期**: M73（已完成）
- **关联**: platform_sync（sync.job 事件）、VideosView（同步任务覆盖层）、R-070/081/087/088

## 处理
1. 后端：SyncJob 创建/进度/完成统一广播 `sync.job`（job_type/scope/creator_id/status/progress/note）。
2. 前端素材库：
   - 收到 sync.job 事件或轮询到 running 的 daily/initial/weekly 任务且属于当前视图博主时，当前视图内已有云端卡**立即进入同步覆盖动画**（文字显示任务当前阶段，如评论采集/下载/转写中）；
   - 某条卡随后进入独立媒体任务时，动画切到该任务自己的精确进度；
   - 任务结束/失败或切换博主时清理；切页回来由轮询自动恢复。
3. 仍遵循：全量/每周只同步数据（会进入同步动画，但不下载视频）。
