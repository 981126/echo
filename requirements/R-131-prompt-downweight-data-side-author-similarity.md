## 原文（作者原话，未改动）
> 2.ai提示词这个功能，我原本只是想让系统的ai自动生成文案的时候不偏离大方向，生成的脚本像作者，现在看起来ai提示词功能是不是没什么必要了？或者你有什么建议吗

（后续作者在上一步二选一中确认：**A（推荐）——降权 generation 自动优化 + 重心转向数据侧**。）

## 诊断依据（代码事实）
- `GENERATION_SYSTEM` 全文仅约 **260 字**（角色 + 一句"严格模仿作者语气" + 输出 JSON 结构）；「像作者」几乎全部由**运行时注入**承担：
  人设档案（含维度）、红线、金句锚点、语言习惯画像、风格样本、AI 腔禁词、最佳实践、对标风格卡。
  → 自动"优化"一条已把所有事委托给运行时的提示词，**能改的只有措辞，杠杆很小**。
- R-129 实测印证：优化器唯一能想到的"加强"就是**把作者传记/红线写进提示词**，而这正是必须禁止的（会造成"两份人设"）。
- 真正的杠杆在数据侧，但有 4 个点没吃满：
  1. **作者改写稿未进入生成上下文**：`original_script` 只用于 diff 分析、提示词优化语料与评测，**没做生成 few-shot**；
  2. 风格样本只检索 **3 条**（`_style_samples` k=3）；
  3. 「最佳实践」只有 **3 行概括**（`_best_practice_lines`），不是可模仿的开场/结尾结构；
  4. 生成后**没有自检**（红线/口癖/AI 腔词），坏了也没有补救。
- **数据底子现状（2026-09-10 实测）**：非广告素材 225 条、其中有转写稿 215 条；AI 草稿 5 篇；
  「AI 原稿 ≠ 作者改后」的成对样本只有 **4 对**；**草稿评分/采用反馈 0 条**。
  → 数据侧增强必须「有就用、没有不报错」；同时需要引导作者积累反馈，否则最强信号始终是空的。

## 范围
1. **降权 generation 自动优化**：取消「每 3 条新素材自动产出候选」与「每周日自动产出候选」，
   改为累计到阈值时**发通知提示可手动优化**（不自动烧钱）；规则型 key 的自动优化能力保留但默认关闭（可开关）。
2. **数据侧增强（"像作者"的真杠杆）**：
   - ① 把作者认可的「AI 原稿 → 作者改后」成对样本作为 few-shot 注入生成上下文（0 对时不注入）；
   - ② 风格样本检索条数可配置（默认 3 → 5~8），并支持把素材标为**风格范本**（优先注入、不被检索淘汰）；
   - ③ 高表现稿的**开场句/结尾引导句结构模板**（取代只有 3 行的概括）；
   - ④ 生成后**自检**（红线命中 / AI 腔禁用词 / 口癖覆盖率 / JSON 合法），不达标自动重写 1 次并留痕。
3. **反馈数据引导**：生成/保存草稿后引导作者打分（当前反馈为 0，是最缺的一环）。
4. **提示词页重定位**：页头说明改为「支架 + 高级设置，默认不建议改」；generation 卡片标注自动优化已改手动。

## 不包含
- 不改动人设提取/增量管线（R-128 已定稿）；
- 不删除 AI 提示词功能（保留版本/编辑/回滚/评测）；
- 不引入向量库（仍用现有 TF-IDF + 规则自检）。

## 验收标准（初稿）
1. generation 不再自动产出候选；素材/反馈累计到阈值时只发一条可读通知。
2. 有「原稿≠改后」样本时生成上下文出现 few-shot 段；0 对时该段不出现且不影响生成。
3. 风格样本条数可配置；被标为风格范本的素材必定出现在生成上下文中（在样本段内标注为范本）。
4. 生成上下文包含开场/结尾结构模板（来自高表现稿的真实片段）。
5. 生成后自检：命中红线或 AI 腔词/格式非法时自动重写 1 次，并在草稿上留可查痕迹。
6. 草稿保存后有打分引导（不打扰、可忽略）。
7. `scripts/verify.sh` 全绿；接口冒烟；服务保持运行。

## 实施记录（2026-09-10）
- **降权**：`tasks._maybe_optimize_prompt` 不再自动产出候选，改为 `prompt_service.maybe_notify_prompt_refresh`（累计 10 条素材发一条提醒）；
  `scheduler._weekly_style_job` 改为每周只发提醒（job id `weekly_prompt_hint`）；删除 `auto_optimize_generation`。
- **偏离说明**：原方案写「规则型 key 自动优化默认关闭、设置里可开」，实施时改为**手动一键** `POST /api/prompts/optimize-rules`
  （后台任务 `optimize_rule_keys_task`，逐 key 产出候选、样本不足自动跳过），并在提示词页加按钮——
  理由：后台自动触发即使默认关闭也需要一套设置 UI 与节流状态，而手动一键同样达到"只对规则型 key 优化"的目的且更可控、不会不可见地烧钱。
- **数据侧增强**：
  - `generation._rewrite_examples`（改写稿 few-shot，优先高分/采用；无成对样本返回空）；
  - `_style_samples` 条数可配置（Kv `style_sample_count`，3~8，默认 5）+ `_style_anchor_samples`（Kv `style_anchor_video_ids`，必定注入）；
  - `_structure_templates` 取代 `_best_practice_lines`（高表现内容开场/结尾；无反馈时退回高互动素材）。
  - 人设页新增「生成风格范本」勾选（候选按权重 Top20）+ 风格样本条数；`PUT /api/persona/style` 扩展 `anchor_ids` / `sample_count`。
- **生成后自检**：`generation._self_check`（红线命中 / AI 腔禁用词 / 口癖覆盖率）→ 不达标自动重写 1 次（附失败原因）；
  结果写入新列 `drafts.quality`（attempts/issues/passed/style_coverage/mock），`DraftOut` 已带出。
- **打分引导**：首页生成提交提示 + 草稿打分处提示「打分是 AI 学你偏好最强的信号」。
- **提示词页重定位**：页头改为「支架 + 高级设置」；generation 卡片标注「自动优化已改为手动」。
- 实测：`generation_user_message` 已包含「作者对 AI 初稿的真实修改」（当前 4 对样本）与「内容结构模板」；风格范本段在未勾选时不出现。
- 测试：`test_r130_r131_data_side` 13 用例（few-shot/范本/样本条数/结构模板/自检+重写+版本记录/提醒阈值/规则型批量）；verify 全绿。
