# R-122 来源素材链接跳转素材库应直接打开并回显（跨博主云端作品）

- **日期**: 2026-09-07
- **状态**: ✅ 已完成
- **排期**: M104（已完成）
- **关联**: VideosView.handleDeepLink / works API、R-046 素材库深链、R-090 通知深链跨博主、R-117/R-120 source_ref 来源跳转

## 原文（作者原话，未改动）
> 1.点击脚本工作台【来源素材】后的链接，跳转到素材库后，不应该提示（未在当前素材库找到该云端作品（可能属于对标博主）），应该直接打开，并回显数据出来

## 根因
脚本工作台「来源素材」链接携带 `#/videos?post=<平台作品 id>`（来自洗稿 source_ref.post_id）。
素材库深链处理只会在「当前筛选博主」的云端作品里按 id 查找（R-046 实现），找不到就提示
「未在当前素材库找到该云端作品（可能属于对标博主）」；
而洗稿来源素材属于对标博主（如 R-117 落库的 source_ref.kind=benchmark），不在当前主博主列表 → 弹提示且打不开。
R-090 只修了本地素材（edit= 深链按 /api/videos/{id} 拉详情），云端 post= 深链未同步修复。

## 处理方案
- 后端新增 `GET /api/works/by-post/{post_id}`：按平台作品 id 反查其所属博主，
  用与素材库同口径的 list_works 返回包含该作品的云端条目（合并作品或单条）。
- 前端 VideosView 深链：当前列表找不到 post 时，调 by-post 接口拉取该云端条目并直接打开弹窗回显；
  若该帖已转本地（local_video_id）则打开本地编辑。找不到（已删除/账号禁用）才提示。
- 更新 docs/API.md（新增路由）、CHANGELOG/PRD/里程碑；verify.sh 全绿。

## 验收
- verify.sh 全绿；新接口测试通过；前端 lint/build 通过。
