# R-213 断网兜底：草稿「本地暂存 + 自动重试 + 恢复提示」

- **日期**: 2026-09-29
- **状态**: ✅ 已完成（M205）
- **关联**: `frontend_v2/src/pages/drafts/autosave.ts`、新 `local-copy.ts`、`edit-drawer.tsx`；R-212（新建草稿实时保存）、R-202/R-175（动效与可见性规范）

## 原文（作者原话，未改动）
> 如果我断网了呢，现在是检测改动就保存吗？

## 现状排查（修复前实测，Playwright 拦住 `/api/drafts` 写请求）
| 场景 | 实测 |
|---|---|
| 断网后继续打字 | 状态位 `自动保存失败，点【保存】重试`（每次改动仍会尝试，且每次发**完整内容**） |
| 停下不再打字 5s | **0 次自动重试**，一直卡在失败态 |
| 断网期间关抽屉 | 服务端没有这张稿，**localStorage 里也没有任何副本** → 内容真丢 |
| 网络恢复后继续打字 | 自愈（`已自动保存`） |

结论：是「检测改动就保存」，但**只在网络可达时有效**；停手不重试、断网期间关抽屉/刷新即丢。

## 反问与确认结论（2026-09-29）
1. **兜底层次**：**本地兜底 + 自动重试 + 恢复提示**（不选「只加重试」——那样关抽屉/刷新仍会丢；也不选「暂不动」）。纯前端改动，后端零改动。
2. **恢复形态**：**提示条让作者选**（【恢复】【丢弃】），**不静默覆盖**服务端内容。
3. **本地副本口径**：只保留**一份**「尚未同步到服务器」的副本（`localStorage`，键 `echo_v2_draft_local_copy`，含内容 + 写入时间 + 草稿 id）；服务器确认落库后**立刻清掉**，不做已同步内容的缓存。
4. **重试策略**：网络/5xx 类失败按 `1s → 2s → 4s → … → 30s` 退避重试（不设总次数上限，页面活着就一直试）；浏览器 `online` 事件立即重试；**4xx（请求本身有问题）不重试**，直接报失败（重试没意义）。
5. **动效（R-175/R-202）**：恢复提示条与状态位都用 `softIn`（`0.85 → 1` + y，**不从 opacity 0 起步**），收口 `opacity 1 / transform none`；离线态状态位显示「连不上服务器，已本地暂存（重试 N）」，不允许静默失败。
6. **清空即无副本**：内容全空时不留本地副本（与「空稿关闭自动删除」口径一致）。

## 做法
- 新 `local-copy.ts`：`readLocalCopy / writeLocalCopy / clearLocalCopy`（脏数据/隐私模式/配额满都不抛，读坏返回 null）。
- `autosave.ts`：
  - **改动先落本地**（`schedule()` 里、防抖之前）→ 断网/刷新/关抽屉都留得住；
  - 新增 `pending`（最新一份未确认落库的内容）：成功落库且没有更新的 `pending` 才 `storage.clear()`（避免把并发期间更新的副本提前清掉）；
  - 失败分类：`4xx → 'error'`（不重试）；其余 → `'offline'` + 退避重试（重试读 `pending`，抽屉已关也能补存）；
  - 新增 `flush()`（恢复副本/立即补存）与 `retryNow()`（`online` 事件）；`markSaved/discard` 同步清副本；`dispose` **不清副本**（这正是兜底的意义）。
- `edit-drawer.tsx`：打开抽屉时读一次副本，仅当「副本 id 与当前稿匹配（副本 id=0 ↔ 新建草稿会话）」时在表单上方显示提示条（`data-testid="draft-local-copy"`）——【恢复】回填内容、【丢弃】删副本；`online` 事件触发 `retryNow()`；状态位新增离线态与重试次数。
