# R-185 内容机会引擎：评论聚类选题榜 + 选题账本 + 每周灵感包

- **日期**: 2026-09-28
- **状态**: 🔲 已确认方向，待实施（系统「初心」的核心缺口）
- **关联**: `topic_ideas`、`topic_candidates`、`hot_topics`、`services/pipeline.py`、主页；R-028/R-030/R-072/R-140

## 原文（作者原话，未改动）
> 做这个系统的初心就是，博主越做越久话题就会越来越少，越来越没灵感，你觉得这个系统缺少什么核心的东西

## 背景
现有选题只「供给」不「规划」：灵感池已积 2,889 条评论（全部未用），但每日只消费「最近一条」；
缺「我讲过什么、还剩什么没讲」的账本，也没有可经营的选题地图。

## 方案
1. **评论聚类选题榜**（P0，数据现成）：把 2,889 条评论按问题聚类 + 计数 + 时间趋势，
   产出「观众提问 TOP 榜」（同一问题被问 N 次 = 强需求）。
2. **选题账本**：记录话题 × 角度消费状态（没讲 / 讲过一次 / 该续集 / 过度消耗）+ 生成前**角度级消重** + **枯竭预警**。
3. **每周灵感补给包**（替代/补充每日自动生成）：`需求强度 × 你的独特性 × 新鲜度 × 可讲证据 × 当前缺口`
   评分，一次产出 10–20 个带推荐理由的选题供挑选，挑中一键进生成。
4. 选题资产字段：观众问题 / 独特答案 / 证据资产 / 内容形式 / 系列进度 / 结果。

## 验收
- 评论聚类榜可展示并解释；选题账本能去重与预警；每周灵感包可产出带理由选题并一键生成；
- `scripts/verify.sh` 全绿。
