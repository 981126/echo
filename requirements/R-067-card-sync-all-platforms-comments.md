# R-067-CARD-SYNC-ALL-PLATFORMS-COMMENTS: 素材库卡片「同步数据」补齐三平台同步 + 评论按点赞 Top50 入库

- **日期**: 2026-09-06
- **提出渠道**: 对话
- **原文摘要**: 1) 点素材库卡片「同步数据」没有同步三个平台的数据，只提示同步但平台数据没变；2) 点卡片「同步数据」要把评论也同步过来，每个平台点赞量最高的前 50 条。
- **状态**: ✅ 已完成
- **排期**: M49（已完成）
- **关联**: PRD §3.1/§3.5/§3.10/§3.11、R-027/R-028/R-036/R-037

## 现状核对（2026-09-06 代码检查）
1. **云端合并卡**（同一作品三平台合并为 type=work 的卡片）：卡片「同步数据」只调 `POST /api/platform/posts/{cloudPosts[0].id}/sync`，即只同步**第一个平台**那一条帖子的指标，其余平台不更新；提示也只报"已同步 平台名"。
2. **本地已绑定素材卡**：`POST /api/platform/videos/{video_id}/sync`（sync_local_video_metrics）会遍历绑定平台拉指标，但**不同步评论**；且前端 syncData 成功后不刷新卡片（无 load/loadQuiet），卡片三平台行仍显示占位/旧值。
3. **评论现状**：`fetch_comments` 只返回评论文本（无点赞数，单次最多 20 条）；`platform_post_comments` 表无点赞字段；评论数据 tab 只能手动「加载评论」，与卡片「同步数据」无关。结论：评论根本没有随「同步数据」入库，也无法按"点赞 Top50"筛选。

## 处理方案（待作者确认后实施）
1. 评论结构化：数据源返回 `CommentData(text, likes, user_nick)`；TikHub real 解析各平台评论点赞数（抖音 digg_count / 小红书 like_count / B站 like）；mock 用确定性种子造数（含点赞，排序稳定），离线可验收。
2. `platform_post_comments` 增加 `likes` 列（Alembic 迁移）；入库按文本去重/更新点赞。
3. 卡片「同步数据」统一为：同步该素材**全部绑定平台**的最新指标 + 每平台评论**点赞 Top50** 入库。
   - 云端合并卡：新增 work 级同步（合并作品下全部平台帖逐条同步），前端 type=work 卡不再只同步 cloudPosts[0]；
   - 本地素材卡：`sync_local_video_metrics` 内补评论同步，前端同步后静默刷新。
4. 评论读取按点赞数降序返回 Top50；评论数据 tab 展示点赞数（与手动「加载评论」共用同一入库函数）。

## 反问清单（默认结论，作者可修正）
1. **范围与边界**：修卡片同步（三平台全同步）+ 同步评论（每平台点赞 Top50）。不含：评论自动进选题池（沿用 R-028 现有逻辑不动）、不含移动端展示优化。
2. **场景与影响**：素材库卡片点「同步数据」后，卡片与评论 tab 能看到三平台最新数据与评论；整号同步（run_sync）与单帖同步统一复用同一评论入库函数，行为收敛。
3. **数据**：评论文本 + 点赞数 + 昵称；real 来自 TikHub 各平台评论接口，某平台拿不到就跳过该平台并提示，不中断其它平台；mock 造确定性数据。
4. **边界与异常**：空评论 / 单平台失败 / 重复评论 / 超过 50 条——按文本去重 upsert、逐平台 try/except 不中断、只保留点赞最高 Top50。
5. **验收标准**：verify.sh 全绿；接口冒烟（本地绑定三平台、云端合并 work 均返回多平台指标 + 评论 Top50）；前端点检（同步后卡片刷新、评论 tab 有数据与点赞数）。
6. **成本与性能**：real 每帖多 1 次评论请求，受既有额度护栏（2000/天）约束；同步为手动低频操作。
7. **依赖与风险**：TikHub（已接入）；挂掉逐平台跳过并提示，不影响已有数据。
8. **优先级**：现在做（M49）。

## 处理结论（2026-09-06，作者已确认实施）
1. **云端合并卡**：新增 `POST /api/platform/works/{work_id}/sync`，同步合并作品下**全部平台帖**（指标 + 评论）；前端卡片按钮按 work/post 分流，不再只同步 cloudPosts[0]
2. **本地已绑定素材卡**：`sync_local_video_metrics` 逐个同步绑定平台并**同步评论**；前端 sync 后静默刷新卡片
3. **评论点赞 Top50**：数据源 `fetch_comments` 返回结构化 `CommentData(text/likes/user_nick)`；`platform_post_comments` 增 `likes` 列（幂等迁移）；入库按点赞降序保留每平台 Top50、文本去重；评论读取接口按点赞降序返回 Top50，评论数据 tab 显示点赞数与昵称
4. 手动「加载评论」与卡片同步、整号同步共用同一评论入库函数；mock 确定性造数（含点赞），real 解析各平台点赞字段
5. 幂等：重复同步不重复新增（只更新更高点赞）
6. 自测：verify.sh 全绿（51 测试）；HTTP 冒烟通过（本地三平台 / 云端合并卡 均返回 3 平台 + 每平台 50 条按点赞降序；再次同步 0 新增）
