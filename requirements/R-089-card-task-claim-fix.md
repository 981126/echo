# R-089-CARD-TASK-CLAIM-FIX: 素材卡能“认领”后端任务 + 进度不回退

- **日期**: 2026-09-06
- **提出渠道**: 对话（R-088 后反馈）
- **原文摘要**: 1.博主页面点击同步，素材库还是没有动画；2.素材库点击同步，进度 60% 后又掉到 30%；3.素材库点击同步出现动画，切页回来又没了；4.现在的异步操作在后端有留痕吗，否则切换回来怎么会又不见了。
- **状态**: ✅ 已完成
- **排期**: M71（已完成）
- **关联**: schemas/task.py（TaskOut.payload）、tasks.py / media_ensure 事件带 payload、VideosView（认领/单调进度）、R-081/R-087/R-088

## 结论与修复
1. 后端**留痕完整**：background_tasks（含每条平台媒体的 post 任务）、sync_jobs、notifications 都在（实测 132 条任务，下载中/转写中任务在库）。前端丢是因为拿不到“任务对应哪张卡”。
2. 根因：任务列表接口 TaskOut 未返回 payload，前端切页回来扫描 running 任务时无法映射到卡片 → 动画不恢复、博主页触发的媒体任务不被素材卡认领。
3. 修复：
   - TaskOut 增加 payload；task.update 事件与 /api/tasks 都带 payload（work/post/video）。
   - VideosView 支持按 payload 即时“认领”任务（SSE 事件或 6s 扫描均可），切页回来自动恢复。
   - 覆盖层进度改为单调不回退（请求阶段 60% → 后台任务从 2% 起不再覆盖成低值），同卡已有任务时不重复替换。
4. 自测：verify.sh 全绿；后端已重启；库内 running 平台媒体任务可被卡片认领。
