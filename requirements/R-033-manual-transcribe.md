## 反问与确认（2026-09-05）
1. **抽音轨**：本地视频先用 ffmpeg（`imageio-ffmpeg` 自带静态二进制，无系统依赖）抽成 16k 单声道 wav 再上传 OSS；纯音频（wav/mp3/m4a/...）无需抽离直接上传；识别完成后删除 OSS 临时对象与本地临时 wav
   - 收益：上传体积从数百 MB 降到几 MB；`.mov` 不在 FileTrans 官方支持清单，抽成 wav 顺带规避兼容风险
2. **手动转写**：`POST /api/videos/{id}/transcribe` 启动后台任务（复用 import_video_task 全链：转写→AI 校对→预打标/人设建议）；上传接口与 inbox 监听只入库、不再自动触发转写；已转写完成再次触发返回 400
3. **前端**：素材库上传/转本地提示语更新；编辑弹窗在「原始文案」上方新增「语音转文字」按钮（有本地视频且未转写时显示），点击后轮询详情，完成后自动展示只读转写稿；右上角通知可跳转
4. **存量 bug 修复**：`app/tasks.py::_maybe_optimize_prompt` 相对导入写错（`app.prompt_service` 不存在），导致每次转写成功后又把任务误标「失败」并弹失败通知 —— 已改为 `app.services.prompt_service`，验收确认任务状态为 done

## 验收（2026-09-05 实调）
- 单测：新增音频抽离/直接上传/清理等用例（当前 45 项通过）；ruff/mypy/前端构建全绿
- 真实链路：用含音轨的 3 秒 mp4 → 自动抽音轨上传 OSS → FileTrans 返回「北京的天气。」→ 临时文件清理（bucket 无残留）
- 接口流程：上传后立即查询转写稿为「无」→ POST /transcribe 返回 task → 轮询回填「北京的天气。」→ 重复触发返回 400 → 任务状态 done、无 error、完成通知已生成
