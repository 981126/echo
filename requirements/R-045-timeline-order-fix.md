# R-045-TIMELINE-ORDER-FIX: 时间线最新素材仍不排第一（同日扇出挤位）修复

## 根因与处理（2026-09-05）
1. **根因**：时间线同一天多条时“以当天为中心 ±94px 左右错开”；当相邻两天很近（例如 09-04 与 09-02 只差 2 天、像素间距仅 10px）时，09-02 那几条的错开卡片会**向左溢出到 09-04 前面**，再按位置排序后把《豆包》挤到后面
2. **处理**：改为严格按“最新→最旧”顺序逐个排布：同一天多条按序排开（不再向左右错开），相邻不足最小间距时只往右推；用真实数据验证：第一条 = 豆包 09-04，日期严格倒序、left 严格递增
3. 复核确认：R-043（事件 key 唯一 + 全量拉取）与 R-044（未来过滤）均已生效；本次为剩余的视觉顺序 bug
