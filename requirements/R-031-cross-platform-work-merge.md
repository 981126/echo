# R-031-CROSS-PLATFORM-MERGE: 素材库跨平台同作品合并（自动 + 手动）

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 同一内容发三个平台 = 同一个作品；素材库可查看该作品各平台数据，也支持手动把多个素材标识为同一作品；同一作品不要在素材库重复显示成三条。
- **状态**: 实施中
- **排期**: M13
- **关联**: PRD §3.1/§3.10（待补充）

## 原文（作者原话，未改动）
> 1.如果三个平台的作品发现标题是一样的，那就说明是同一个作品发了三个平台，素材库可以看到三个平台这个作品的数据，也可以手动将三个素材标识成同一个作品，同一个作品不要在素材库显示成三个素材。

## 确认与实现（2026-09-05）
- 模型：works 表；platform_posts.work_id / videos.work_id 归属
- 自动合并：同创作者（主/对标各自独立）+ 规范化标题相同 → 自动归为同一作品（同步后执行）
- 手动合并：素材库「云端作品」面板勾选 ≥2 条 → 合并为同一作品；可整组拆分还原
- 展示：同一作品在素材库只出现一条，内部展示抖音/B站/小红书各自的播放/赞/藏/评数据，支持按平台单独同步
