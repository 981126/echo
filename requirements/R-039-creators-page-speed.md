# R-039-CREATORS-PAGE-SPEED: 博主页加载慢优化

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 为什么点击博主这个页面，数据加载这么慢。
- **状态**: ✅ 已完成
- **排期**: M21（已完成）
- **关联**: PRD §3.5/§3.10

## 原因与处理（2026-09-05）
1. **主因**：页面加载串行请求，其中 `GET /api/platform/budget` 每次都会**同步请求第三方 TikHub 查余额**（httpx 超时 12s），实测单次 ~0.7-0.8s，网络慢时可能数秒，把整页卡在 loading
2. **处理**：`/budget` 默认只读本地预算（毫秒级），余额仅 `?refresh_balance=true` 显式拉取（页面当前并不展示余额）；博主页前端把 creators/current/budget/summary 改为 `Promise.all` 并行请求
3. 复测：budget ~0.8s → ~1ms；creator-summary ~20-55ms；页面整体应基本秒开
