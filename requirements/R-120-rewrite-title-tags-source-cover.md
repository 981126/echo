# R-120 洗稿标题/标签/来源跳转/封面字

- **日期**: 2026-09-07
- **状态**: ✅ 已完成
- **排期**: M102（已完成）
- **原文**:
  1. 洗稿后的标题不能和对标素材文案标题一致
  2. 脚本工作台的脚本编辑窗，素材tag单独给个文本框
  3. 来源素材可以直接点击跳转到对应素材库的卡片
  4. 封面字也需要生成

## 实施
1. 洗稿初稿改为 JSON 输出 `{title, cover_text, script}`：title 重新拟（与素材原标题不同，兜底加「·口播稿」）；cover_text 生成 3-8 字封面字。
2. `drafts` 新增 `tags`；洗稿时把对标素材标签带入，编辑窗加「素材标签」文本框（逗号分隔，可编辑并保存）。
3. 草稿编辑窗「来源素材」标题可点击，跳转 `#/videos?post={post_id}`（复用素材库深链）。
4. 对标 item 序列化新增 `tags`，随洗稿请求传给后端。

## 验收
- 洗稿草稿标题与素材标题不同；有封面字；素材标签独立文本框可编辑；来源素材可点击跳转素材库。
- `scripts/verify.sh` 全绿。
