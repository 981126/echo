## 背景（问题）
现有档案把「稳定写作 DNA / 内容立场 / 某期具体主张 / 真禁区 / 临时状态」混在一起、同权重注入生成；
增量校验因「只新增不淘汰 + 只算新增覆盖」覆盖率长期 0–4%、每次回退全量（`persona_checks` 38 条全 fallback）。

## 方案（方案B：推倒重建）
### 1. 档案分层（`persona_tags` 加 `layer` 字段）
- `core_dna` 核心人格与语言 DNA：**只留 6–10 条**，稳定、高辨识；
- `stance` 内容立场与可信经历：可随创作演化；
- `mode` 创作模式：犀利干货 / 个人独白 / 热点评论 / 实验复盘；
- `forbidden` 真正禁区：平台风险 / 商业边界 / 绝不表达。
- 每条补 `evidence`（证据视频）、`frequency`（出现频次）、`last_seen_at`（最后出现时间）、`confirm_strength`（确认强度）。

### 2. 红线重分类
现有 9 条「红线」多为**立场**（如「不主张面试完全诚实」「不推荐招聘平台」），
移出 `forbidden` → 归入 `stance`；`forbidden` 只留真正的行为禁区，避免误伤热点筛选与让模型困惑。

### 3. 差异单取代建议堆积
人设任务产出「本次建议：新增 / 合并 / 过期」三段差异单（不再每次塞几十条待确认）；
档案支持过期淘汰；比对口径同时计算新增与过期，修掉「永远覆盖不到」的结构性失败。

### 4. 实施要点
- **推倒重建**：清空现有 confirmed/rejected，重新跑全量提取 → 分层归纳 → 作者一次性确认（方案B）。
- 生成/改写上下文按 `layer` 分组注入（core_dna 权重最高，stance 次之，mode 按本次创作模式筛选）。
- 前端人设页按四层分区展示 + 差异单 UI。
- 迁移：`_migrate_persona_layer` 加列（幂等），重建由后台任务执行。

## 验收
- 分层字段落库；差异单可新增/合并/过期；红线重分类后 `forbidden` 仅剩行为禁区；
- 人设任务不再产生堆积（一次任务 = 一份差异单）；
- `scripts/verify.sh` 全绿 + 前端人设页四层展示点检。
