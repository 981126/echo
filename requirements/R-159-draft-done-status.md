## 范围
- **状态**：`drafts.status` 新增 `done`（完成）；`DraftCreate` / `DraftUpdate` 的 status 白名单加 `done`；
  AI 对话只读视图 `v_drafts.status` 说明同步补 `done=完成`。
- **前端**：tab 变四个「草稿 / 待制作 / **完成** / 废稿」（工作流顺序）；
  待制作卡加【完成】（→`done`）与【退回草稿】（→`draft`），保留【移入废稿】【删除】；
  完成卡提供【退回待制作】（→`used`）与【删除】；深链打开时切到对应 tab（含 `done`）。
- 状态流转均为 `PATCH /api/drafts/{id}`（只改 status，不动反馈）；删除仍走 R-158 的二次确认逻辑删除。
