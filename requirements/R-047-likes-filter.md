# R-047-LIKES-FILTER: 素材库按点赞量筛选（多平台任一命中）

- **日期**: 2026-09-05
- **提出渠道**: 对话
- **原文摘要**: 素材库添加筛选条件，点赞量大于、小于多少，任意一个平台匹配就行。
- **状态**: ✅ 已完成
- **排期**: M29（已完成）
- **关联**: PRD §3.5/§3.10

## 处理结论（2026-09-05）
1. 素材库工具栏新增「点赞 ≥ / ≤」两个数值框（可清空），与其它条件一起点「查询」生效
2. 判定：素材各平台最新点赞里**任一平台**落在区间即命中（≥ 与 ≤ 可单独或同时使用）
3. 说明：无平台数据的本地素材在启用点赞筛选时会被过滤掉（没有可比的点赞数据）
