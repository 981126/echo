# R-208 自动化加固与系统瘦身（去审批化，聚焦「话题+文案」核心）

- **日期**: 2026-09-29
- **状态**: ✅ 已完成（M198–M202）
- **关联**: persona/ingest、prompt_optimizer、pipeline/mailer、frontend_v2 prompts/chat、scheduler、R-131/R-138/R-139/R-141/R-147/R-182/R-188/R-197

## 原文（作者原话，未改动）
> 这个系统你觉得有什么比较重要的东西还没有，还是现在这个系统是不是臃肿了？需要删除一些东西，我更想要的是自动化的，我不想经常上系统这里需要我审批那里需要我审批，我需要它提供符合我这个博主人设的话题，和大概的文案，这是最核心的

## 反问与确认结论（2026-09-29，作者已逐项拍板）
1. **人设建议自动化**：**高置信自动 + 红线人工**。出现频次高、与已确认档案无冲突的「内容立场/创作模式」层标签自动确认（审计 + 通知 + 可一键撤销）；「禁区/红线」层永远人工确认；现存堆积按同规则批量处理。
2. **提示词优化**：**后台全自动**。到量自动跑优化 → 金样本回放评分 → 明显更好（≥+10%，可调）自动启用并通知（附变更说明 + 一键回滚），不更好静默丢弃；删除 `weekly_prompt_hint` 定时任务；提示词版本/评测 UI 收进「高级」。
3. **每日「今日最佳」推送**：**AI 选 1 篇推送全文**。每日流水线收尾按「人设契合 × 热点热度」从当天 3 篇选最佳 1 篇，邮件 + 站内通知推送「选题理由 + 完整口播稿全文」，手机上看一眼即可开拍；邮件失败不影响流水线（沿用 R-141 次要通道原则）。
4. **瘦身范围（作者全选）**：
   - AI 设置页大瘦身：10 tab 收为「基础」（模型/Key/ASR/每日篇数/讨论轮次）+「高级」（推理预算、提示词版本等）；
   - AI 对话写操作白名单自动执行（生成草稿/灵感提炼/打标等安全操作不再弹确认，审计照记；删除/覆盖/改配置类仍需确认）；
   - 清理复盘遗留代码（`metrics_snapshots` 及 metrics 服务死代码，保留雷达给 AI 对话）；
   - 下线老前端 `frontend/`（删目录、verify 去构建、根路径指 frontend_v2）。
5. **非目标**：素材库/对标/工作台/灵感随手记不动；「表现反哺选题自动倾斜」暂不立项（归因数据不够厚，M200 跑一两个月后再议）。
