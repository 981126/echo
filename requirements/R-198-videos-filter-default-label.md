# R-198 素材库筛选下拉默认态：文案纠正 + 不高亮

- **日期**: 2026-09-28
- **状态**: ✅ 已完成（M187）
- **关联**: `frontend_v2/src/pages/videos/index.tsx`、`components/ui/filter-value.tsx`、R-164/R-179

## 原文（作者原话，未改动）
> 1.素材库广告搜索条件 里面 为什么是默认 广告二字，很容易误解啊，这种下拉框里面的默认lable 不要高亮，并且改成是否广告，发布状态

## 根因
筛选项的「全部」项文案被写成了**字段名**（`<SelectItem value="all">广告</SelectItem>`），而 Radix 的
`SelectValue` 只要 `value` 非空就按**正常前景色**渲染选中项文字。于是默认态（未筛选）看起来跟
真的筛了「仅广告」一样——高亮 + 写着「广告」，两处叠加造成误解。状态下拉的「全部状态」同理。

## 做法
- 新增 `components/ui/filter-value.tsx`（`FilterValue`）：默认态按**字段名 + `text-muted-foreground`** 展示，
  选中具体值才恢复正常前景色并显示该值。
- 素材库工具栏 4 个下拉统一接入：博主（默认「当前主博主」）、发布状态、有无视频、是否广告。
- 文案：状态下拉默认标签 `状态/全部状态` → **发布状态**；广告下拉默认标签 `广告` → **是否广告**；
  视频下拉统一为 **有无视频**。下拉内的「全部」项保留（用于取消筛选），选中态勾选不变。
- 交互/动效不变（Radix 弹层开合动画沿用），只改触发器的文字与颜色，无新动效需求。

## 验收
- 单测 `components/ui/filter-value.test.tsx` 3 例（默认灰字 / 选中恢复正常色 / 拿不到值文案回落字段名）。
- `frontend_v2`：`tsc --noEmit` + `eslint src` + `vitest run`（43 例）全绿。
- 页面点检：默认态呈灰字「当前主博主 / 平台 / 发布状态 / 有无视频 / 是否广告 / 标签 / ≥ 点赞」，
  选「仅广告」后变正常色「仅广告」，选「全部」回到灰字。
- `scripts/verify.sh` 全绿。
