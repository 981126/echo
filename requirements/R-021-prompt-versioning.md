# R-021-PROMPT-VERSIONING: AI 提示词查看/编辑 + 版本化自动优化

- **日期**: 2026-09-03
- **提出渠道**: 对话
- **原文摘要**: 新增菜单可查看/编辑当前 AI 提示词；每次上传新视频后，基于当前启用的提示词版本自动优化并生成新版本启用；历史版本归档，可选择启用历史版本。
- **状态**: ✅ 已完成
- **排期**: M9
- **关联**: PRD §3.2/§3.4/§3.5（已更新）
- **反问与确认**:
  - 范围：每个功能（生成/人设初始化/视频预打标/人设增量/复盘/改稿/对话/校对）都有提示词管理，页面 tab 切换（已确认）
  - 自动优化：上传新视频后基于当前启用版自动产出**候选新版**（不直接启用），页面提示待启用，可一键启用（已确认）
  - 手动编辑保存：另存为新版本并启用，旧版归档（已确认）
  - 失败处理：AI 优化失败保留当前版本并提示（已确认）
  - 入口：侧栏新增“AI 提示词”菜单（已确认）

## 原文（作者原话，未改动）
