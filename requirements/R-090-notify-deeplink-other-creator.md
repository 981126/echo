# R-090-NOTIFY-DEEPLINK-OTHER-CREATOR: 通知跳转素材编辑不受当前博主筛选限制

- **日期**: 2026-09-06
- **提出渠道**: 对话
- **原文摘要**: 素材库选择了其他博主时，在通知栏点击「素材转写失败」的素材，没有出现编辑弹窗。
- **状态**: ✅ 已完成
- **排期**: M72（已完成）
- **关联**: VideosView.handleDeepLink / goLocal、NotificationBell、R-032/R-077 通知深链

## 原因
通知深链 `/videos?edit=id` 只在“当前筛选博主”的本地素材列表里找素材，找不到就静默不打开；
当素材库筛选到其它博主、而失败素材属于另一个博主时，编辑弹窗不出现。

## 处理
VideosView 深链处理：列表里找不到 editId 时，直接按 id 调用 `/api/videos/{id}` 拉详情并打开编辑弹窗
（复用 goLocal 逻辑），不再受当前博主筛选限制；素材不存在时才提示。
纯前端改动；verify.sh 全绿。
