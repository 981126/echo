## 处理结论（2026-09-05）
1. **封面/视频上传不再退出编辑页、不再闪**：
   - 编辑弹窗内上传/移除封面：只更新封面并**保持弹窗打开**，后台静默刷新（新增 `loadQuiet/loadWorksQuiet`，不再整页 loading 闪屏）
   - 顶部上传视频成功：静默刷新后**直接打开该素材编辑弹窗**（少一次点击、无闪屏）
   - 云端「转本地素材」保存：改为静默刷新后再打开本地编辑弹窗（去掉中间闪屏）
2. **三平台视频链接展示**：素材详情接口新增 `platform_links`（按 work 聚合该作品绑定的各平台帖子），由平台作品 id 构造网页链接——B站用 raw 里的 bvid（兜底 aid→av 链接）、抖音用 aweme_id（优先原始 share_url）、小红书用 note_id；编辑弹窗「发布链接」下方以胶囊链接展示（抖音/B站/小红书 ↗，点击新窗口打开）
   - 新增纯函数 `core/platform_links.py` + 3 条离线单测
