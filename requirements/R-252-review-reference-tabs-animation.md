## 现状核对（2026-11-05）

1. 切换「同行爆款/低粉爆款」时：`loadReferences()` 先把 `referenceLoading=true` → 页面把整个网格替换成一个 `Loader2` 转圈 → 数据返回后再整片渲染新卡片。旧卡片先消失、新卡片瞬间出现 → **一闪/空白**，没有任何过渡动画。
2. `更新`按钮只在 `kind === 'low_fan'` 时渲染，切换到低粉时 DOM 突然多发一个按钮，把前面两个 tab 按钮向左挤 → **突兀 + 布局跳动**。
3. 网格为 `md:2 / lg:3 / xl:4` 列，1440 宽一行 4 条；标题没有行数限制，长标题会撑到 3~5 行，卡片高低不一。
4. `refreshLowFan()` 执行时没有 loading 状态，按钮可重复点击。

## 一、需求背景

参考视频区是复盘页很常用的区域，但切 tab 会闪、更新按钮突然挤出来、卡片一次性出现，观感不流畅；同时 4 列偏大、长标题把卡片撑高。作者希望切 tab 像卡片轮换一样有过渡动画、按钮平滑出现，并一行看 5 条、标题最多两行。

## 二、想要实现的目标

| 目标 | 可验收标准 |
|---|---|
| 切换不再闪白 | 点「低粉爆款/同行爆款」时，旧卡片保持到新数据到达（不出现空白帧/整片转圈替换）；新卡片以淡入+上移逐张入场 |
| 每张卡片有过渡动画 | 新卡片 opacity 从 0.85→1、y 从 8→0，stagger 约 0.03s；旧卡片退出淡出/缩小约 0.16s；过程中无布局跳变 |
| 更新按钮平滑出现 | 切到低粉时「更新」按钮以宽度+透明度动画展开（约 0.2s），前两个按钮被平滑推开而不是瞬间位移；切回同行时平滑收起 |
| 一行 5 条 | 宽屏（≥1280px）每行 5 张；1024~1280 4 张、768~1024 3 张、手机 2/1 张 |
| 标题最多两行 | 长标题截断为 2 行（省略号），鼠标悬停显示完整标题；卡片高度不再被长标题撑开 |
| 不破坏其它功能 | 加载/空态/封面兜底/方向过滤逻辑不变；更新时按钮显示「更新中…」并防重复点击；console 0 error |

## 三、页面数据来源

| 页面字段 | 数据来源 | 更新时机 | 缺失/失败表现 |
|---|---|---|---|
| 同行/低粉卡片列表 | `GET /api/douyin-review/references?kind=peer|low_fan&limit=20` | 首次进入 / 切换 tab / 点「更新」任务完成后 | 首次无数据 → 转圈；切换时保留旧卡片直到新数据到达；空列表 → 现有空态文案 |
| 卡片封面 | 同 R-249：本地 `/covers/*`（缩略+缓存版本）或远程签名 URL，失败 ECHO 占位 | 页面加载 | 占位/兜底 |
| 更新按钮 | 前端状态（仅低粉 tab 显示） | 切 tab 时动画展开/收起；点击后后台刷新任务 | 更新中显示转圈+「更新中…」，禁用防重复 |

## 四、功能需求

### 4.1 切 tab 的加载与动画

- `loadReferences(kind)`：不再让整个网格变成转圈；当**已有卡片**时保留旧卡片显示（网格轻微变淡表示加载中，`opacity-60` 平滑过渡），新数据到达后替换；
- 只有**首次加载且没有任何卡片**时才显示转圈；
- 卡片用 `AnimatePresence mode="popLayout"`：
  - 新卡片入场：`opacity 0.85→1`、`y 8→0`、`scale 0.99→1`，每张延迟 `min(index,8)*0.03s`；
  - 旧卡片退场：`opacity→0`、`scale 0.96`，约 0.16s；退场卡片不占位，新卡片立即排版（无高度跳动）；
- 网格容器不再整块卸载重挂，避免闪白。

### 4.2 更新按钮入场/退场动画

- 用 `AnimatePresence` + `motion.div` 包裹「更新」按钮：`maxWidth 0→120`、`opacity 0→1`，约 0.2s；切回同行时反向收起；
- 前两个 tab 按钮保持固定位置，被平滑推开/收回，不再瞬间位移；
- 刷新过程：按钮显示 `Loader2` 转圈 +「更新中…」，`disabled` 防重复点击；失败 toast 后恢复。

### 4.3 一行 5 条 + 标题两行截断

- 网格断点：`grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-5`（1440 宽实测 5 列）；
- 标题 `line-clamp-2`（最多两行、省略号），`title={item.title}` 悬停看全文，`min-w-0 flex-1` 防止与右侧徽标挤压；
- 其余字段（作者/粉丝/播放点赞评论/倍数/查看原视频）不变。

## 五、空数据 / 失败表现

| 情况 | 页面表现 |
|---|---|
| 首次加载、无任何卡片 | 显示转圈（原有行为） |
| 切换 tab | 旧卡片保留 + 轻微变淡，新卡片动画替换；无空白帧 |
| 请求失败 | toast 错误；保留 old cards；console 不报错 |
| 空列表 | 现有空态文案 |
| 更新中 | 按钮「更新中…」+ 禁用；完成后新卡片动画入场 |
| 封面失败 | 沿用 R-249 ECHO 占位 |

## 六、边界与不做

1. 只改参考视频区（视频复盘页下半部分），不改其它页面；
2. 不改接口/加载条数（仍 20 条）/方向过滤/封面兜底逻辑；
3. 不做 tab 下划线/滑块等额外导航动效（按钮颜色过渡已有）；
4. 不强制卡片等高（标题两行后大部分高度接近即可）。

## 七、用户故事

1. 作为作者，我在「同行爆款/低粉爆款」之间切换时，希望卡片像列表轮换一样有过渡动画，而不是闪一下或转个圈。
2. 作为作者，我切到低粉时希望「更新」按钮平滑出现，而不是突然把前面两个按钮挤开。
3. 作为作者，我想一行看到 5 条参考视频，标题太长显示两行省略，不要参差不齐。

## 八、验收标准

1. Playwright 逐帧采样：切换 tab 期间卡片数量始终 > 0（无空白帧）；新卡片 opacity 有中间值（0.85→1 动画）；旧卡片有退场。
2. 「更新」按钮切到低粉时宽度有中间过渡值（0→57→74px），前两个按钮平滑位移；切回同行时平滑收起。
3. 1440 宽：一行 5 张（20 条呈 4 行 × 5）；1024~1280 4 列、768~1024 3 列、手机 2 列。
4. 长标题：2 行截断（`clientHeight ≈ 2×lineHeight`、`scrollHeight > clientHeight`），悬停 `title` 显示全文。
5. 加载/空态/封面/更新中/失败提示正常；console 0 error；`verify.sh` 全绿。
